# Corporium

面向田野语言学调查的本地多语言工作区。文本标注、词典与共享语素、语法调查、音视频时间轴和语料分析共享材料与引用，数据保存在本机 SQLite 中。

文档整理于 **2026-11-09**。使用说明以本文为准；开发接续见 [DEVELOPMENT_HANDOFF.md](DEVELOPMENT_HANDOFF.md)，各轮经过与原始证据见 [DEVELOPMENT_HISTORY.md](DEVELOPMENT_HISTORY.md)。

## 启动与项目

| 方式 | 入口 | 说明 |
| --- | --- | --- |
| 源码桌面开发版 | `Open-Corporium-Dev.cmd` | 使用本机 `.desktop-venv`，打开当前项目，默认端口 18766 |
| 浏览器版 | `Open-Corpus.cmd` | 启动后台服务并打开 `http://localhost:8765/`，需要本机 Python |
| Windows 安装版 | `release/Corporium-0.9.01101-Windows-x64-Setup.exe` | 包含运行依赖，无需另装 Python；自动恢复上次成功打开的项目 |
| 免安装应用目录 | `release/app-0.9.01030/Corporium/Corporium.exe` | 须保留整个目录及其依赖 |
| 命令行调试 | `python server.py --port 8765` | 在项目目录执行；Ctrl+C 停止服务 |

**开发版会直接修改所打开项目的真实数据，不自动建立测试副本。** 试验性批量操作请先备份，或将备份恢复到独立项目。桌面版可新建项目、打开已有项目、将完整备份恢复到新的空文件夹；不要把项目保存在程序安装目录中。卸载程序不删除外部项目。

项目的主要文件如下：

| 路径 | 内容 |
| --- | --- |
| `data/corpus.sqlite3` | 正式工作数据库 |
| `data/backups` | 升级／打开项目等操作产生的一致快照 |
| `data/media` | 复制进项目的媒体与附件 |
| `media/recordings` | 正式现场录音原件；与 `data`、`font` 并列，试音不自动保存 |
| `data/media-cache` | 可重建的媒体／波形缓存与相关设置 |
| `data/templates/grammar` | 语法调查文件模板 |
| `font` | 项目自定义字体；可放整套子文件夹后扫描 |
| `import typ` | 导入材料，不是实时主数据库 |

开发版配置／日志在 `%LOCALAPPDATA%/Corporium-dev`，正式版在 `%LOCALAPPDATA%/Corporium`，浏览器启动日志为 `data/launcher.log`。后端代码改动需停止服务或关闭开发版再启动；重复双击可能只唤起旧进程。前端改动通常刷新即可，关闭浏览器页不会停止后台服务。

安装时每次显示目录选择页，默认仍为当前用户的 Programs/Corporium，升级时可调整位置。安装许可接受并入原有最后确认页：可选查看全文，点击“同意并安装”，不增加独立许可页或额外勾选。第三方许可保存在安装目录 `_internal/licenses`，应用代码签名留待正式发布。当前源码可点击底栏版本号，或从“管理 → 备份与关于 → 关于与许可”查看简介、版本、开发者 **Erči Ša.**、主页、Issues、版本复制和折叠的许可全文；署名固定使用 Junicode，不显示邮箱。未打开项目时也有查看入口。

安装包提供可选的虚构示例语言 Tëlira（573 词条、2 文本、168 句）：通过“语言选项 → 导入语言数据包 → 使用内置示例 Tëlira”导入，不自动改写现有语言。发行包不包含正式调查库、`test_media` 或私人字体；随附 Junicode 和 STIX Two Text，Microsoft JhengHei仅调用系统已有字体，不复制或打包。项目没有 IPAPANNEW 时允许回退显示，可放入自有字体后扫描。

| 管理 | 书写类型、附加层、类、合作者、语言标记、快捷编辑管理、备份和关于 |

左上只有 Corporium 品牌返回欢迎页。语言名称右侧的小下拉切换语言；“语言选项”提供新建、设置、导入和导出。独立例句、调查和时间轴侧栏不显示这组管理按钮，仍保留语言切换。语言信息中分别设置名称、别名、本地名称及 IPA／语素／标注／自由翻译四行的字体、变体和字号比例。比例放在对应变体右侧，随语言保存在项目中；语言间互不覆盖。

删除语言：打开语言信息窗口，双击底部的“删除语言（双击）”，核对资料数量，再双击警告窗口的“确认删除（双击）”。两处单击均不执行删除。删除包含本语言的文本、词典、独立例句、调查、时间轴、配置及撤销记录；共享合作者和语言标记、原媒体文件保留。有其他材料仍引用本语言或其定义时，会提示先调整引用。删除前在项目 `data/backups` 保存 `before-language-delete-*.sqlite3` 完整备份；删除不能通过撤销恢复。删掉最后一种语言后仍可新建或导入，重启不会自动重新添加已删除语言。

侧栏用边缘窄把手收起／展开，分隔条可调宽，按模块记忆。桌面侧栏展开时最小尺寸 1100×600；收起后允许缩至当前显示器可用逻辑宽度约一半，宽度下限 480、上限不超过原 1100，高度仍为 600。跨显示器会重算，浏览器自己的窗口尺寸由浏览器控制。

欢迎页统计所有语言的文本、文本句与独立句、词条；同句多次引用不重复计数。轮换池包含未关联词条的独立句，可暂停／换句／点击查看来源，音频处只保留播放按钮。轮播按累计10秒展示时间换句，音频加载和播放期间暂停，结束、停止或失败后接着计时；例如播放前已展示3秒，结束后继续7秒。手动暂停、悬停／焦点和后台暂停仍有效。轮播区IPA按语言字号加大12%，译文缩小8%，不影响普通例句的统一默认字号。页面固定视口，长例句按可用宽高局部缩小字号，短句恢复正常，不截断原文和译文。

第二行工具栏提供简要模式、自动关联、撤销／重做及上下文查找替换；“收起工具”位于右侧。文本／独立句的检索把手在第二行下方，默认收起、分别记忆，随顶栏悬浮。词典左侧和调查笔记检索也默认折叠；折叠不清空条件。

## 文本、独立例句与标注

### 导入、组织与交换文本

Typst 导入支持 `#gloss`／`#pass`，可混用字符串和方括号，不执行任意 Typst 程序。例如：

```typst
#pass([soma], (([soma], [家]),), [家。])
```

程序保留来源文件、行号、原始调用及稳定 ID；阅读页句首只显示语言、文本和句号等必要信息，不显示函数名／源行。变量求值、任意宏展开与完整文档排版不支持。相同导入按内容去重；修改外部源文件不会自动覆盖程序中的编辑。

文本侧栏底部“新建／导入／导出”集中操作。文本可拖入同语言文件夹或前后排序；文件夹齿轮管理名称、备注和顺序。删除文件夹不删文本。文本元信息包含多合作者及角色、时间／地点／材料编号／限制、备注与自定义字段；“文本操作 → 文本信息与阅读设置”先选择实际文本，在“全部文本”中不会打开一个空的编辑表单。

每句“更多”可复制、移动、调整句序；批量选择支持跨页，可复制／移动到同语言文本或拆分新文本。复制创建独立身份并携带标注、分析、引用；移动保留原句身份。拆分保持原顺序并继承元信息，合并可指定前后次序。操作可撤销；删除句子点击后确认，删除文本双击后确认。

Excel 在文本导入／导出窗口选择 `.xlsx`，每张表确认起始行与列映射。语素／标注列必须成对指定，单侧空值仍保留对齐；IPA、译文、备注和附加层可选。按空行或 SentenceID 分句，句级内容可配置连接符。先预览后整体导入，不创建／修改语言。

导出可选当前语言多个文本，生成多表 Excel 或多个 Excel 的 ZIP；SentenceID／WordIndex 保留空句和空词格。桌面使用原生保存窗口，浏览器按保存选择器或下载设置处理。映射方案属于本机偏好。当前 Excel 限 14MB、20 万行／表；公式只读已保存缓存值，合并单元格需预先处理。

Word 文本导入／导出在文本侧栏选择 `.docx`，一次导出当前语言的一个文本；导入窗口提供空白模板。长句允许多个表格处于同一例句范围中，不按换行、换页或表格数量分句。预览每页20句，点词格间“↵”拆句，或点“与下句合并”；展开可修订 IPA、译文、备注。拆句后的句级字段留在含原句起点的部分，需人工核对。附加层按本语言映射，确认后创建新文本，支持整体撤销、重做。

这一版只接收标准 DOCX，旧 `.doc` 需先另存；不自动识别任意旧文档，不覆盖原文本，不重新关联词典。词典关联、形态／重叠关系等研究资料请使用语言包或完整备份。文件最多14MB；模板编辑方式、格式与限制见 [Word 标准文本交换](docs/DOCX_TEXT_FORMAT.md)。

### 共用句子编辑器

文本、独立例句、词典／语素例证、调查和时间轴复用原位“编辑标注”。新建句子直接进入同一编辑器，保存后才建立记录，允许空句。完全空的未保存新草稿离开时舍弃；有内容需先保存／取消。逐行录入保留在“更多 → Tab 编辑”，“编辑信息”与“编辑标注”是不同操作。

同一句在多个位置出现时共用当前草稿；保存或取消后，各处立即结束这句的编辑，其他句子尚未保存的草稿保留。重新读取期间显示简短更新提示，不展示已经结束的旧编辑框。

- 点击语素／标注输入格选择整个词格对，用本句共用工具区末尾添加、后方插入、向后合并或删除，不为每格重复放整套按钮。排序使用拖动，不再提供词格“前移／后移／移动到”。
- “向后合并词格”把当前格与下一格的词形、标注直接拼接，不额外插入空格或短杠；同一附加层以空格连接。保留左格身份，原引用和旧分析保留核对依据；保存前可取消，保存后可一步撤销。
- 末尾已有内容时按 Tab 新增下一词格；Shift+Tab 后退，中文输入法组合中不误触。拖动模式支持 Ctrl 多选、Shift 连选。
- 保存时清理各位置完全空的词格对／可对应成分，包括被清空的标点与井号；只有一侧为空不删除。旧附加标注和引用恢复资料随撤销保留，不擅自移给其他词。
- 清空复合标注的一项会移除多余连接符：`GEN.SG` 去掉 SG 后为 GEN；`root-GEN-NOM-` 不保留尾部短杠。有效的上下标／括号保留，仅处理实际编辑内容，不批量清洗旧语料。
- “保存时按语素行空格分词”只作用于本次句子；已有保护内容或分词数量不一致时须先处理。
- 词格复制可跨同语言文本／来源；词格移动限同一文本内，独立句只在独立库内移动。先选目标范围再选句子；携带词级附加层、分析和关联，不自动改整句 IPA、译文、人员或时间。

例句仍需显式保存；刷新不能恢复未提交草稿。撤销重做保留当前页和阅读位置，被撤销删除的阅读锚点使用相邻句或原滚动位置。

“补全空白标注”与“编辑标注”并列；人工“形态分析”在每句的“更多”中。完整例句的共享操作覆盖文本、独立库、词典／语素例证、调查和时间轴，简要模式仍隐藏编辑操作。

“识别并拆分标点”先预览，支持整文本、单句或选中的独立句；无标注／分析／关联／附加层的明确标点可在保存时自动识别。遇到 `!` 先确认它不是搭嘴音。纯 `#`／`##` 等是可按语言命名的音系边界，不作为普通词／语素关联。标点和边界两侧均分既有间距，五种皮肤一致；调查引用的语素行遵循本语言字体、变体和比例设置。

### 重叠与基底

例如 `je~jepasu`：在“编辑标注”中选中 `je`，点击“关联重叠基底”，选择本句的 `jepasu`，指定部分重叠／完全重叠／变形重叠／未细分，可按需填写备注。关系随整句“保存”生效，取消例句草稿会放弃关系修改；从“形态分析”打开时直接保存关系，支持撤销。

`~` 只提出相邻部分供核对，不自动判断重叠方向、音节或语法意义，不自动生成词典变体或复制基底标注。也可关联跨词格的部分、整词或已有人工词干组合。文本句、独立句及其共享引用使用同一关系；只读分析卡片显示关系摘要。

补齐上一轮遗漏的整词重叠：整个词格都是已确认的重叠成分时，其有效基底范围已关联词典，即显示关联完成下划线；解除基底关联后同步消失，撤销／重做同步恢复。支持跨词格基底、指向具体语素／组合及连续重叠关系。基底只关联其他片段、未覆盖被选范围时不算完成；失效／待核对关系不传播完成状态。显示计算不生成重叠部分自己的词典关联。

词格中已确认重叠关系的重叠部分不再要求单独入典；其余成分全部关联词典后显示关联完成下划线。例：`je~jepasu`中确认je重叠自jepasu，只关联jepasu即可完成；`je~jepasu-na`中的na仍须关联。仅有`~`候选、失效／待核对关系不免除要求；没有实际词典关联的纯重叠词格不会凭空完成。不修改已存词典关联或统计次数。文本、独立例句、词典例证、调查、时间轴及分析共用此判断，重叠关系编辑、删除及撤销后随读取刷新。

拖动沿稳定词格身份保留关系；改写／合并／删除导致任一端无法确定时，保留原关系并提示“待核对”，不会按新位置猜配。整句复制使用新的身份；只复制关系的一端时保留待核对记录，需重新选择基底。待核对关系不进入有效关系统计。

文本与独立库检索、语料分析均可选“重叠基底”，留空查全部有效关系。Typst 在句前保存不影响排版的专用注释；含关系的 Excel 导出新增 `Reduplication` 列，重新导入时映射到“重叠关系”。语言交换、分析 JSON／固定快照和完整备份保留关系。详细规则见 [形态分析](MORPHOLOGY.md)。

### 检索、简要模式和查找替换

可检索 IPA、形式、语素、标注、译文、备注及附加层，也可按关联词典条目的自定义书写形式检索；层次下拉框列出各层和书写类型的名称。隐藏层可显式选择，失去词格对应的旧值与失效独立句关联不纳入。选择包含／完全／开头／结尾、大小写及检查条件。备注检索涵盖句子、句子语言备注和文本备注。“本语言全部文本”可同时列出文本句与独立句，独立句不因多个引用重复。检索清空不改变当前语言／文本。

简要模式突出例句内容，右上只保留播放与纯文本发言人，隐藏编辑、形态分析、更多、录音选择等；没有媒体或姓名不造占位。各模块例句、对话及分析结果遵循相同规则。退出恢复操作；正在编辑的新句仍有保存／取消。

顶部“重做”右侧有查找替换。文本范围为整篇当前文本或本语言所有文本，独立句范围为本语言独立库，均含所有页面；两者不受普通搜索结果过滤。可分别替换 IPA、语素、标注、译文，以及单个或全部自定义标注层。逐词附加层按词格处理，IPA／译文下的整句附行按整行处理；包含隐藏或未参与普通检索的层，失去对应词格的旧标注不纳入。字面匹配，不执行正则、不跨词格。

先预览，再逐处／全部应用；空替换明确表示删除，逐处操作不再次处理刚插入的内容。每次应用一步撤销。结构／关联冲突须确认，可定位原句；不合法括号等阻止保存，数据变化后须重新预览。失效旧分析保留依据，不自动改挂同形对象；提示统计与剩余结果一致。

## 词典与共享语素

### 列表、检索、排序和批量

侧栏用“词条／语素”切换对象，两者相同行高、形式与词类／简短释义同行。形式沿用对应语言的语素字体／变体且保持粗体，超长名称悬停或聚焦往返滚动。每页可选 10、20、30、50、100、200、500、1000 或全部，记忆选择；超过 200 条使用可见行渲染。词条支持本页全选／半选和跨页累计，只有一页时隐藏分页／跳页。

“检索词典”含搜索、按类查看与查找替换，统一放大镜在模式菜单旁。条件支持字段、包含／完全／开头／结尾／不包含／已填／未填、全部满足或任意满足；字段包括自定义书写、用法义项、标签、特征、形式、分析、类及关联例句。条件按整个条目组合，不要求同一义项同时命中。类别筛选父类包含后代，词条和语素按各自字段生效。

词条和语素均从“每页”左侧齿轮打开各自的排序设置：

- 自定义字母／多字符单位顺序，最长匹配优先，未定义字符按 Unicode 排在后面；默认忽略大小写、保留附标区别并统一规范等价形式。
- 词条／语素分别可按添加时间正序／倒序并记忆；不明的旧时间保留未知且置后，不编造导入时间。
- 词条另可按分类层级排列：组合词类／子类、语义类、形态类、形式类型、使用标签类型和语法标签分类；拖动层级、同级类与类内条目，也可用方向键。类标题醒目，可折叠并记忆；拖动只改变显示顺序，不改变归类。此模式不用于语素。

齿轮与“每页”之间是词条批量编辑：词类／子类、语义类、形态类、条目类型、整个条目的使用标签与固有语法特征。集合可添加／移除／替换，不批量改释义或书写。先预览；替换已有内容需确认，保留用法／义项身份，整批一步撤销。分类、显示排序和已知添加时间随备份／语言交换保留；当前选择和折叠是本机偏好。

### 词条、快捷编辑和语素

语素关联框保持紧凑宽度；长内容在鼠标悬浮或键盘聚焦时横向滚动，完整文字也可从原生下拉选项和悬停提示查看。选择和原有键盘操作保持，启用减少动态效果时停止滚动动画。每份分析下方的操作采用统一常规高度，窄窗自动换行。

快捷编辑的书写形式每行显示类型下拉框、内容和最右侧“×”，名称不再重复占行；旧的未归类名称仍可从下拉框识别。语素拆分表在形式、读音、释义和各书写栏内按↑／↓，切换到上一／下一条可编辑语素的同一字段并选中文字；只读的已关联语素跳过，排序后仍跟随当前行序。

词条和语素详情的“复制”建立独立条目，自动分配新身份、添加时间和同形编号；保留各级释义、书写、变体、形态表／分析、共享语素关联、同义关系和媒体。媒体复用原文件，现有语料与独立句引用仍归原条目；复制不产生额外例句。整次可一步撤销／重做，纳入备份及语言交换。复制完成显示副本，刷新失败会明确告知副本已保存。

词条义项和语素的简短释义保持自由文本，附加标签单独保存，可从本语言已登记语法标签选择；继承内容以数字结尾时直接连写（如3sg），其他情况用点号连接。每个义项的“显示附加标签”决定组合结果；取消勾选保留标签内容。完整／快捷编辑共用草稿，阅读、自动匹配和跟随标注采用组合结果，本句覆盖保留。查找替换的简短释义只修改自由文本，避免把组合显示写回原字段。

类列表行首把手可拖动排序，也支持 Alt＋上下键；只调整同级顺序，保存、重载、语言交换和撤销均保留。重命名同步更新引用，删除前说明对子类和绑定的处理。删除词类解除词类／子类绑定；形式类型删除后保持未指定；使用标签类型解除相应标签；语法标签分类删除保留标签定义和特征引用；形态类删除保留未分类的主要词形与备注；语义类沿用提升／删除子树选项。词条／语素编辑时管理分类保留草稿，独立窗口的并发修改仍受版本校验。

清空词格时，只剩 `-、=、+、~、<>、＝` 的空内容在保存时移除；真实词形、非空标注和转义字面符号保留，附加层／原身份可撤销恢复。文本新句在当前列表末尾原位编辑，仍追加到文本末尾；保存后保留卡片、当前页与筛选，下次检索按正常分页显示。

词条可有多个词类用法和义项；义项分别保存简短标注、详细释义、特征、使用标签和说明。同义关系建立在具体义项之间。条目、用法、义项和变体的标签作用范围不同，语法特征与地域／文体等使用标签也不同。

右上“编辑词条／管理媒体／删除”，完整编辑尽量在页内。书写及形态类／主要部分紧接核心字段，形式／变体、形态分析与关系在义项下可展开；空部分不占行。新增而完全空白的行保存时舍弃，已有／被引用／部分填写对象继续校验。

编辑状态右上“取消编辑”左侧打开快捷编辑：词形旁选类型，固定书写栏目、词类／义项简短标注紧凑成行，形态分析默认展开。义项／组分可拖动排序；语素行按搜索、形式、读音、书写和释义排列。搜索结果显示已有书写／释义，选中后填入只读共享内容。它与完整编辑共用草稿和保存，同形确认、自动整理及撤销规则相同。“管理 → 词条快捷编辑管理”设置本语言必显书写栏目。

语素是语言内独立目录，不是词条上的一个字符串。可编辑形式、简短标注、类型、意义／功能及标签、读音／书写、条件变体和备注，管理图片／录音、查看关联组分及例句。意义／功能按需展开，不提供词类占位和同义入口。

只有类型为词缀时显示构词功能与位置；屈折／派生和前缀／后缀／中缀／环缀分别记录。词条类型已移除“普通语素”；旧记录不自动转换。词条右上“转为语素”先预览，同形记录由用户确认独立转换或并入已有语素，保留意义、书写、分析、媒体、引用及来源，支持撤销。

词条分析组分可“关联已有语素”，再选择基本形式或某个具体变体，直接显示形式、读音、释义、书写，不要求重输。完整编辑、快捷编辑及“整理组分为语素”均支持；变体有独立读音时优先使用，否则沿用语素读音。保存后按语素／变体的稳定 ID 保留选择，重新编辑不会退回基本形式。

保存新组分也可自动整理为语素。同形时选择已有或新建独立记录，不强制合并。修改共享语素时，仍沿用原共享值的组分及同音表更新；基本形式和各变体分别同步，单独填写的不同实现及未关联组分保留。关联、同步及归并可撤销／重做，随备份／语言交换保留。仍被组分关联的变体须先调整关联再删除。

词条和语素的变体均支持条件、语法特征、使用标签、来源和备注。**分布条件始终可留空，选择“条件变体”也不强制填写。** 关系与条件记录独立保存，不会为保存而强改成自由变体。

### 词形变化表、模板与多部分形式

词条可添加一个或多个变形表，按自定义栏目组织形式、详细释义和简短标注；同一格可有多个形式和意义，区分“未填写”和“无此形式”。“管理 → 变形表模板”按语言保存栏目、行类别及预设附加标签，修改后同步到已有实例。新增项自动出现；删除已有内容的行或整个模板时列出影响并确认，取消不改动，确认后可一步撤销。未删行的填写内容、自建行和单独修改的预设标签保留；词形变体与例句正文保留，已删除意义的例句关联解除。

标注模式可选“独立标注”或“继承＋附加标签”。例如基本义项为 `1SG`，各形式只填 `NOM`／`ACC`，最终得到 `1SG.NOM`／`1SG.ACC`；附加项可选本语言已有语法标签。默认继承来源可在表头选择，每个形式意义也能单独调整；切回独立模式冻结完整标注。旧表默认独立，不擅自改写。检索、关联、自动匹配、分析和导出使用最终标注。

普通详情中完整标注与继承说明同行；快捷编辑每行直接填词形和标注，显示最终结果，其他设置点“⋯”展开。Tab 连续填格，Enter 沿同列换行。新填词形直接保存时自动登记为变体；若移除／清空了表格仍需的共用变体，保存会从草稿恢复其形式、身份和附加信息。要彻底删除该形式，须同时移除表中引用。无法确定词形时提示具体表和行并保留草稿。义项排序、删除后的显示编号自动更新；仍按原义项身份关联，删除继承来源时保留完整标注并转独立模式。

词条“词形”右侧勾选“不连续多部分形式”，按顺序填写 2–12 个部分；语素选“词缀 → 环缀”则填写两个必需部分。自动关联按已有切分、完整标注、部分顺序和连接位置核对，环缀两端与中间成分须以短杠相接；`PST-go.PST` 不会仅凭重复 PST 被当成环缀。三部分重复词根也可匹配登记的多部分形式。唯一、无冲突的候选可预选，仍须确认；已有人工分析、语法特征和备注保留。“形态分析”继续提供人工组合与核对。

### 关联与同步

点击例句词格打开共用右侧面板，在“词典关联／形态分析”间切换。整词、语素片段可关联词条或语素及具体意义、可选形式／变体。句级独立例证引用不冒充逐词关联。语素行整词下划线表示整词有关联，或全部分析成分均有关联；部分成分关联不显示整词下划线。

**关联具体义项后默认继承该义项的简单标注释义。** 文本句和独立例句均支持“更多 → 标注来源”：可选择整词或具体语素，改为“本句单独标注”（允许空白），也可恢复跟随词典。直接编辑已关联的标注也会建立本句覆盖。解除关联时冻结当时显示的标注，之后不再跟随。未选具体义项、未关联或失效的旧引用保留原值。

| 修改 | 同步范围 |
| --- | --- |
| 某义项简短标注 | 明确关联该义项且处于继承模式的标注在读取时更新；本句覆盖不变，保留其他语法特征，不逐句写回 |
| 基本形式 | 只更新实际关联该基本形式、能可靠对应的语素行内容 |
| 某个变体形式 | 只更新关联该变体 ID 的内容；即使多个变体同形也分别处理 |
| 详细释义／说明 | 不触发例句标注同步 |

完整编辑、词条快捷编辑、词条／语素查找替换均生效。未关联同形词格、句级引用及失效／无法定位的引用不猜测更新，不改整句 IPA、原文或翻译。保留原边界、上下标和单位身份；不能保持原切分或安全导出时整笔回滚。继承与本句覆盖均支持撤销／重做。检索、标签检查、分析和导出使用当前有效标注；固定分析快照保留保存当时的结果。完整备份保存继承／覆盖及历史来源，语言交换输出有效标注并保留覆盖方式；手动改例句不反向改词典。

文本、独立库、词条／语素例证、调查和时间轴均读取同一源句。词典例证用浅底与边框标出本条目实际关联的词格，而非高亮全部同形词；具体形式只在已选时显示。语素／标注成分列宽共用，字体与文本例句相同。独立例证或引用总数为零时隐藏无用分页与重复空提示，引用为零隐藏例证类型；仅筛选为空仍保留条件。

### 从例句快捷入典与补全空白标注

文本、独立例句及各处引用共用操作。先保存或取消当前例句草稿，再从词格的“词典关联”进入“收入词典”，或点击本句“补全空白标注”。

**快捷入典**的词类下拉始终显示本语言全部顶层词类；“语素”对象及新增语素意义支持独立附加语法标签和显示开关，默认收起，展开后可从已登记标签选择或自由输入。

**快捷入典**预填所选整词、语素或已确认组合的形式和标注。对象统一默认“词条”；需要语素时主动切换。词类可留空、从本语言已有词类选择，或输入新词类，在保存时自动登记。也可关联已有意义、增加义项或登记变体；新建同形记录、替换已有来源关联须明确确认。“保存并关联”与新词类登记在同一次操作中完成，可一步撤销，不另建重复例句；失败保留输入。词典例句区保存后只更新相关卡片、目录计数及侧面板，保留当前例句页码与阅读位置。

**词典候选补空**沿用已有切分，只填空白gloss。主形式、登记变体、形态表形式均可参与；已有具体关联优先。规范等价Unicode视为同形，可忽略词形任意位置的短杠及首尾等号／点号；完全匹配排前，但不屏蔽其他有效候选。同一处最终只有一个有效词典候选时默认选中，仍须确认；多个义项、目标或具体形式由用户选择。单语素整词匹配使用已分析词形，保留原标点。

**整词分析候选**从同语言已有的完整有效关联中复用分析。可分别选择忽略`-、=、+、~、<>`，兼容源码中的`\~`；中缀音段、声调、长音、标点和上下标内容保留。候选显示原切分、标注、义项、来源和用例数，始终逐词手选；采用时恢复切分及关联，并保留有效中缀、词格内重叠、环缀／组合和组分分析。组与重叠局部身份重新分配，目标原词格身份及附加层不变。

同一词格的整词分析与逐语素补全相互排斥。已有非空标注、关联、不同明确切分和手工分析受保护；来源的本句单独覆盖不作为默认分析。跨词格或已失效的重叠基底会提示在本句确认，不按同形词猜配。整句IPA、译文、备注和其他词格不从来源复制。

预览不修改业务材料，可能刷新可重建的查询索引；句子、词典或关联变化后须重新预览。填入、切分和具体关联在同一事务完成，可一步撤销／重做，继续支持释义继承、备份和语言交换。当前不推断新切分、不按译文预测语法，也没有多句／整文本／整库批量补全。[详细使用与适用范围](docs/WORD_ANALYSIS_REUSE.md)。

### 自动关联词典

工具栏“自动关联词典”先选语言／范围并预览，可选具体文本、独立例句库或本语言全部文本。候选包含词条、原生语素及已登记变体，以形式与“简短释义＋适用固有特征”完整匹配；复杂关系不摊平，变体分布条件不自动推理。

规范等价 Unicode 视为同形，如 `ǰ/ǰ、č/č、š/š、ö/ö、ü/ü`，包括其他规范可分解拉丁字母及多个组合附标。只规范比较键，不改存储内容；不抹掉附标，不任意忽略词形大小写。标签别名按标签定义处理。

无竞争的严格唯一义项候选可批量关联，歧义不猜。只有严格匹配时，多个形式都指向同一义项仍可关联义项而不细分形式；既有关联不覆盖。可选择忽略首尾或内部 `- = .`，不是子串模糊匹配；忽略标记的候选会与完全匹配同时列出，后者排前。同一处两组都有候选时，一起移入需确认列表，不会被“关联全部唯一匹配”抢先关联。唯一且无片段冲突的候选默认勾选，适用于词条和语素，仍须确认；多个目标／义项／具体形式手动选择。标注须完整匹配，边界标记选项不放宽释义与固有特征。

候选底栏提供全选／半选及已选数，覆盖尚未展开的所有无歧义候选；同一处多个目标不擅自多选。词例使用语素行字体。点击“关联全部唯一匹配”只处理严格唯一匹配，点击“确认关联所选候选”只处理勾选项；成功后自动更新预览，未处理候选继续保留，仍有效的选择和未选择状态不变，可直接继续另一种操作。其他材料或引用发生变化时，旧预览仍会拒绝写入并要求重新预览。

### 词典查找替换

顶部入口与侧栏替换模式共用：按当前条目或当前语言满足字段／类别条件的所有页面查找，词条与语素都支持。侧栏已输入条件继承到窗口，可继续调整／清空。

已有检索文字时先显示“尚未替换”的查找结果，此时空替换框不表示删除；不可在此替换的类名／引用文字只读显示。填替换内容并“预览替换”后，才可逐处／全部应用。字段包括形式、变体、书写、简短／详细释义、备注、使用标签值；语素另有读音和变体条件。书写可选全部或单个本语言书写类型，涵盖条目书写以及形态分析组分／主要部分中保存的书写，不改变类型名、字体或稳定身份。

每次应用一步撤销；逐处处理固定原范围，保留未处理项。同形重名须确认，不自动归并。空必填值、无效结构或新产生的重复变体阻止应用；预览过期须重来。形式／义项同步遵循上表，不为成功修改制造旧的手动核对提示。

### 语言共用“调查笔记”

调查笔记打开时，在管理中新增、改名、更换字体或删除书写类型，会立即更新笔记的选项和文字显示。删除并转移类型时，同步正文引用、文字撤销历史与笔记版本；先完成待保存内容，再变更类型，保留编辑内容、文字节点和选择范围。选择文字后选取书写类型并点击“应用”即可更换字体，中英文提示同步。实测未发现全局字体覆盖指定书写字体，原问题是打开的笔记沿用旧类型定义。

词典右缘把手开合，左边界调宽（280—640px，受窗口限制），窄窗覆盖显示，记忆宽度和展开状态。顶部保留提示：“调查时可以使用此区域记录内容，方便后续整理”。内容属于当前语言，不随词条／语素选择改变。

笔记可新建、复制、删除、拖动／方向键排序，单条展开用现有富文本编辑器。约 0.9 秒停顿或失焦自动保存；收起、切换、检索、备份／导出、后台任务前等待保存。失败保留草稿，可重试或另存副本；删除／排序和内容支持撤销，连续保存合并记录。

顶部独立检索区默认折叠并记忆，查标题与完整正文；点击结果展开定位高亮，清空恢复列表、展开与滚动。筛选中暂不拖动，不改富文本原始数据。笔记随完整备份和语言交换保留；**尚无从笔记直接建立词条的入口**。

## 标签、形态分析、附加层与语码

“标签与检查”维护本语言正式标签、解释、别名、分类及用例，检查疑似未登记标签、切分不一致、可操作的形态／重叠或附加标注等异常；旧“失效关联”检查及其计数已移除。点击“常见标签参考库”可搜索缩写、中文解释与分类，勾选后先核对再登记；参考库本身不参与正式标签统计。候选区可批量登记或忽略，“已忽略候选”可恢复检查；这些操作按语言保存，整批可撤销，不修改原句。已有标签和别名保留，参考解释不会覆盖本语言定义。

参考术语使用“语式”“示证”，并区分 PFV 完整体、IPFV 未完整体、PRF 完成体和 COMPL 完结体；其他修订见交接中的术语清单。

默认候选仅采用参考库完整缩写，不扫描所有英文词。`house-PL` 只提示 `PL`，`go.PST` 只提示 `PST`；`NOM`／`nom` 都可发现，`all`、`pass` 等易与英文词义混淆的写法保守处理。需要查找自定义缩写时，可临时勾选“扩大候选范围（含普通英文词义）”，或直接新建标签。正式标签优先于候选和忽略；`ALL` 不自动把普通 `all` 当标签，若确需小写形式可显式登记该写法或别名。已存在的小写标签照常识别。

登记后的标签及别名悬停显示解释，`NOM`／`nom` 都用小型大写排印，普通英文词义保持正常字体。原始拼写和大小写继续保存，文本导出不替换为 Unicode 小型大写字符；普通标注输入框保持可辨认的原字母。上下标与括号结构保留，只有实际登记的标签才获得标签排印，例如已登记的 `neg#sub[POT]` 保留小型大写的 neg 和较小下移且大写的 POT。语法标签筛选、统计与自动特征采用正式标签，普通标注全文检索仍可搜索全部原文。检查不代替研究判断。

形态分析中 `- = + ~` 是成分边界；点号分隔同一语素的标注，不增加语素数。下划线`_`是同一标注内的空格替代字符，不是语素或标签边界，`take_care_of`在编辑中占一个格子；`>` 可为论元关系，不能一律当中缀结束。连续中缀按对应片段处理，歧义需确认；环缀／多部分词根／词干可按已登记形式提出候选并由用户确认，也可手动选择成员组合；一个组合计一次。嵌套中缀未支持。

“类管理”按语言维护词类／子类、多级语义类、使用标签类型、形态类和形式类型等。形态类可定义主要部分模板。词条可保存多份共时／历时分析、默认分析、依据和关联；多部分形式在词形／具体形式中编辑，旧组分片段保留供核对；不要求不同书写系统逐字符对应。条件与分析是研究记录，不是自动音变引擎。

例句正文和原位编辑只显示附加层内容，层名可悬停查看，不另占一行。

“管理 → 标注层管理”设置词级附加层、IPA／译文附行的字体、变体、字号、顺序、可见及检索属性。管理窗口内可上下拖动行首把手排序，或聚焦把手按上下方向键；松手自动保存，可撤销。层字号在全局字号基础上相乘：全局110% × 本层110% = 初始121%，阅读与编辑使用同一基准。词级值跟随词格 ID；失效旧值保留，不悄悄挂给新词。

在“管理 → 标注层管理”或“管理 → 书写类型管理”编辑项目，展开默认折叠的“显示设置”，分别设置行前、行后间距。留空沿用默认布局，0 表示该侧不留空；范围 -300–300%，可填小数；负值进一步收紧，100% 等于本行一个字号的高度。支持预览及恢复默认，保存后同一层／书写类型的显示统一更新；不同语言和不同类型独立保存。

### 语码混用

文本与独立例句的“更多 → 语码标记”按词格分组显示语素，可为本句某个语素或连续范围指定语言，无需先收入词典。点击语素单选，Shift连选，Ctrl／⌘切换选择；点击上方词形可选整个词格。环缀等多部分语素整体选择，分隔符和GEN.SG等标签内部的点号不算独立语素。切分不一致的词格先在标注编辑器整理。

使用“管理 → 语言标记”的项目共用目录，可填全称、简称和备注，并可关联现有语言工作区。形式和gloss中的对应小格显示淡底色／细线，保留原有词缀等文字配色；连续范围末格gloss后显示简称，不另占第三行。悬停、点击或键盘激活简称可看全名和备注，IPA旁保留整句语码概况。中英文与Docoid、DAWoid、暖白、夜间、经典苔绿共用同一逻辑。

新标记依附稳定父词格和保存的语素结构。词格移动后随原词格走，新插入未标成分不扩大范围；父词形或原语素结构变动后保留旧范围依据，不能确认的部分不投给新语素，可从原面板重新点选或移除。只改gloss文字、有效切分保持时可继续显示。旧词格标记保持原有显示；只改语言和备注保留完整旧范围，重新点选语素后才按新范围保存。

文本、独立句及分析范围可选不限、仅混用句、已标记，再限定语言。未标语素沿用句子实际默认语言，一个词内部含不同语码也算句内混用。标点和音系边界不参与；未确定或失效旧形式不据以断言语码。全句同一种外语不算句内混用，也不按词源自动判定借词。检索、分析和各语言的句数仍按原句去重，快照保留当时结果。

可手动关联本句、同语言标记的时间轴“语言片段”。改变标记语言同步对应片段；改变实际范围或失效形式后重新选择，会解除旧对应并保留区间，不猜语素时间。单句／词格复制不复制录音对应；整篇文本复制沿用现有独立时间轴副本规则。撤销、备份和语言交换保留范围；带格式复制包含语码细线和普通字形简称，普通文本交换不重建语码关系。原文／IPA局部着色及跨语言词典关联仍未实现。[交互与兼容细则](docs/MORPHEME_CODES.md)。

## 独立例句合法性

**只有独立例句库的句子可以设置合法性**。独立句在词典、调查、时间轴等引用处共享原句状态，保留左侧符号栏；空值表示合法、不显示符号，鼠标移到空白位置可快捷选择，也可从“编辑标注”或“编辑信息”修改。文本句视为合法，不存此字段、不提供选择、不预留符号栏；IPA、首词格与翻译从同一位置开始。没有“未判断”选项。调查的本处判断、判断者和语境保持独立，也可用于文本引用。

“管理 → 合法性类型”按语言维护独立句的名称、符号、说明、显示顺序及是否启用。修改定义不逐句改写；停用保留旧句，新句不提供该选项。使用中的类型不能删除，可先调整独立句或停用；操作可撤销。切换独立句语言后，需重新选择本语言类型。

独立例句检索可按合法性筛选。语料分析“基本内容 → 独立例句合法性”按名称或符号查找，留空列出独立句；对应分布和词句统计只计算独立句，文本句不归入“合法”或“未填写”分组。独立句快照保留当时定义。文本 Excel／Typst 不再提供合法性字段或映射，旧 Typst 合法性附注不再导入；JSON、语言交换和备份继续保存独立句状态与语言定义。打开含旧文本字段的项目时先自动备份再清理，其他句子内容和关联保留；旧撤销、恢复和快照显示／导出不会重新启用文本合法性。

## 独立例句编号、排序和复制

每种语言的独立例句分别从1起分配固定编号。已有例句首次启动支持固定编号的版本时，先自动备份，再按保存的入库先后补号；不改原句身份、内容或引用。修改、成组、检索和切换排序都不换号，删除留下空号，撤销恢复原号；撤销新建也不将已分配的号让给另一句。旧数据没有准确添加时间时，不补造日期。

独立例句库默认“添加顺序：旧到新”，旁边“排序”可切为“新到旧”，按项目和语言记忆。例句组仍以最早成员的入库位置排列，组内继续使用已设置的顺序、a／b／c及Q／A。单句编号在左侧，组成员的固定号显示在原操作栏左侧；同一句进入不同组仍是原号。编号随语言交换及完整备份保留，导入旧语言包时自动分配。

文本页进入“带格式复制”后直接使用句头原有的文本操作勾选框，当前页已勾选项会沿用；“选择本页／取消选择”同步作用于复制选择，退出后保留文本操作选择。左下角“新建＋ → 复制文本”创建整篇独立副本，可修改标题、保留标注和音频对齐，并能一步撤销。

顶部“带格式复制”选择本页例句后，按实际显示顺序为本次所选内容连续编号为（1）、（2）……；整组占一个主号，组内保留原a／b／c、Q／A和合法性。只选组内部分成员时保留其原组内标号。复制编号不使用库内固定号，也不写回材料；字体、上下标及逐词表格沿用原复制流程。

## 独立例句组

此功能仅用于独立例句，文本句子继续使用原有编辑、检索及单句引用。

独立例句库点击“选择成组”，跨页勾选同语言至少两句，再点“将所选句子成组”。在窗口中核对成员顺序、可选组名和共同语境，点击“创建组”。已有句子保持原身份、标注、合法性、词典及媒体关联；同一句可参与多个组，同组不能重复。

“组内标号”可选 a、b、c…（超过 z 后为 aa、ab…）、数字或不显示。角色逐句填写，可留空、选择 Q／A 或自定义；重复角色允许。“填为 Q／A 交替”仅在主动点击时填写。重排自动更新顺序标号，角色随原成员保持；合法性仍按各句设置，独立于组内标号和角色。

“管理组”支持拖动／上下调整、检索并添加已有独立句、移出成员，已有组还可用共用编辑器新建句子并加入（创建句子与加入同一步撤销）。组设置显式保存／取消，失败保留草稿。移出只解除本组关系，解散保留全部原句；仍被调查整组引用时须先处理引用再解散。减少为一句或空组不自动解散，空组暂不能引用；原句删除后组内保留明确的缺失位置，撤销原句删除可恢复。

默认列表显示组与未分组句，可筛选；每页最多20个组／单句单位，组不跨页拆开。同一句在多组出现时统计去重；命中句和陪同显示的成员分开，检索可查组名、共同语境及成员内容。显示组不影响原有按句统计。

调查“引用已有例句”窗口分“单句／例句组”：前者保留文本句、独立句的原流程，后者只列本语言独立例句组。勾选并预览后“引用所选整组”，一次最多20组。本题已有组不可重复引用，原有单句引用不会自动变组。

整组引用跟随源组成员、顺序、角色和源句修改；管理窗口显示受影响的引用数。调查的本处整组笔记、各成员本处判断／判断者／提示／笔记单独自动保存，重排按稳定成员身份对应。成员移出后，本处资料保留在“已移出成员记录”中，可查看和继续编辑。移除调查引用不删除源组或原句，支持撤销。

组结构、退役成员及本处资料纳入语言 JSON／语言包、完整 JSON／SQLite 备份和撤销重做；语言交换重新映射组、成员及源句身份。当前0.9.01101源码与安装包均支持组结构；含组项目不要用不支持分组的旧版本编辑或往返验证。首次升级只新增空目录，在迁移前自动快照，不自动给旧材料成组。

## 语法调查

多级提纲／问题可拖动排序、调整上层和自动编号；默认锁定拖动，可 Ctrl 多选、Shift 连选或用移动窗口。删除需双击后确认，删除提纲不删除所引原句。

编辑直接在卡片内展开，问题说明、研究笔记及例证本处笔记使用富文本，约 0.9 秒自动保存。切换条目／工作区／语言／首页及检索前等待保存；失败保留输入、阻止离开，冲突可将条目字段另存副本。空白新条目不落库，非空但缺标题需处理。**调查文字自动保存，不代表例句标注也自动保存。**

侧栏语言名下、拖动锁定上有紧凑检索：全部内容／调查文字／引用例句。调查文字含标题、说明、研究及本处判断／笔记；引用例句只查调查已引用的本语言文本句与独立句。结果显示路径、字段、摘要，每页 20 组；同处多字段合并，同句不同调查引用分别保留。

点击后保留结果，自动展开、翻到例证当前页并高亮，不改富文本数据。清空恢复原提纲、多选、条目、例证页和阅读位置。支持跨富文本片段及规范等价 Unicode，路径不冒充下级命中。

问题可引用文本句／独立句，或新建独立句；共享原句修改同步各引用，本处情境／判断／笔记独立保存。模板可保存子树或多个一级提纲，支持复制／改名／删除／导入。模板包含结构、说明和书写类型，不带例证、研究笔记或进度，文件在 `data/templates/grammar`，迁移需另行复制。

## 时间轴与媒体

侧栏管理媒体与待对齐句；上方全宽波形／轨道，下方例句与可折叠视频，分隔条可调尺寸。时间轴管理是内部滚动列表，名称、说明、打开／保存名称／复制／删除同行；拖动或方向键排序即时保存，名称草稿保留，顺序可撤销并交换。

媒体支持复制进项目或链接原位置。选句、拖选时间并确认建立句子区间；块中部移动、两端伸缩，同轨碰撞受限，子层需在合法父区间内。删除区间不删原句，点击块只选块，波形点击定位播放头。发言人可沿轨道继承，事件／语言子层分别记录。

### 可选的时间自动句序

侧栏选择具体文本后勾选“按时间轴自动排序”，默认关闭。开启立即按本时间轴重排该文本，以后新建／移动／删除相关对齐区间时更新并保存真实句号。例如 A 在 1–6 秒、B 在 30–35 秒，新增 C 在 10–15 秒后为 A(1)、C(2)、B(3)。

每篇文本只绑定一条依据时间轴；多次对齐取最早起点，同起点稳定，未对齐句依原顺序排末尾。区间与重编号一步撤销／重做，关闭保留已有编号；保存新句与建立对齐仍是两个步骤。全部文本／独立库不启用此选项，设置随备份和语言交换保存。

### 播放、精细波形与缓存

### 播放音量

支持 0–100% 音量，默认 100%。选中已关联音频的文本后，“文本操作”左侧显示文本总音量；悬停或聚焦句子／录音播放键，在旁边展开竖向圆角音量卡片。支持拖动、方向键、静音和恢复默认，卡片不占例句行高；右侧空间不足时移到左侧，保持在窗口内。

文本句子的实际播放音量＝文本总音量 × 句子音量，例如 60% × 50%＝30%。每次从原设置重新计算，播放或切换页面不会重复相乘。同一句子在文本、词典例证、独立例句库、调查、时间轴、分析、标签用例及主页共享设置；独立例句的附件与时间轴对齐音频共用句子设置。词条和语素的各段附件录音分别记忆。时间轴播放完整选中句子区间时沿用该句设置；自由试听其他时间范围时使用该时间轴自己的音量，不额外乘入句子播放。

音量是本机播放偏好，按项目及对象编号保存在本地浏览器存储中；不修改原录音、语料正文或撤销历史，不随项目备份导出。删除浏览器存储或换设备后恢复默认。旧的全局 30% 播放值不再传播到其他对象。中英文控件、提示、无障碍名称一致。

播放有变速、音量／静音、前后两秒、选段与循环。波形／对齐轨道 **Shift+滚轮水平平移，Ctrl+滚轮缩放**，同时按下优先缩放；播放头到右边缘才推进视窗。垂直 1×—4×只改变显示，双声道围绕各自中心缩放。编辑句子时仍可试听／平移／缩放，试听范围不写成区间边界。

波形保留原采样率、分声道，按缩放切换多级峰值和真实采样点连线；最小视窗 1ms，区间按整数毫秒保存。首次后台生成时可播放，角落显示进度。

“音频波形”旁齿轮 →“波形与缓存”：默认 **128MB 内存、2048MB 磁盘**（按 MiB 计算），可调 16–4096／64–65536MB，按项目保存。默认后端缓存 96、单浏览器 32；是缓存预算，不是整个程序内存硬上限。旧细节／概览可淘汰重建，原媒体、附件和兼容播放副本不参与波形淘汰。

DAWoid 轨道齿轮可选预设、自定义色或六位代码，子轨道默认继承父色，也可单独覆盖。颜色是项目数据，增删／排序不改变旧轨道色，副本、撤销、备份及交换保留；其他皮肤保留各自填色。

区间时间失焦／后续操作前自动保存；非法值提示修正。离屏选中块仍保留下方句子。文本、独立句、词典、调查和分析可播放关联片段，视频在句子处只出声音。换源先预览并确认保持或平移；丢失媒体需重链接，不能依缓存替代原文件。

### 词典与独立句附件

词条／语素“管理媒体”及独立句媒体入口共用图片／录音模块。录音可指定变体／主要部分、发言人和片段，排序决定默认录音；发言人与句子人员独立。图片与释义默认 40%／60%，可调 20%—60%，窄列上下排，可放大查看。

支持 JPEG、PNG、WebP、GIF，BMP／TIFF 转 PNG，多页 TIFF 取首页；HEIC／HEIF 和独立视频附件未支持。上传上限 256MB，独立录音最长一小时，长录音可引用时间轴片段。新增附件复制进项目，解除关系可撤销，不立即物理删文件；删除被引用变体前先调整媒体目标。

### 现场录音

词典／语素、独立例句和时间轴共用录音面板，可选设备／规格、10秒试音、查看电平、停止后试听并直接关联。试音仅在内存中，可主动下载，不会改成“另录一次”；正式录音才自动保存到项目`media/recordings`。独立句未关联音频时，“录音”在“管理媒体”左边；有音频后句旁按钮隐藏，媒体管理内仍可继续录制。文本句来自长音频转写，不提供单句录音。

电平／过载反馈在面板内显示，不反复弹窗。录音中先停止再切项目或界面语言；撤销关联不会删除原件。模拟设备和合成波形测试不替代现场音质验收，首次使用先试音。[规格、恢复与备份](docs/RECORDING.md)。

## 语料分析、同音语素表与人员

语境索引支持形式、语素、标签、词典目标／词类、整句 IPA、译文、备注，以及同词／同句／词距和否定条件。可看频率／分布、定位原句与前后文、保存子语料／收藏／固定结果快照、收入研究分组。自定义字段按范畴再选具体字段。

MPW（morphemes per word）按形式行有内容的语素小格总数除以词格数，不要求关联词典。勾选“MPW：附着成分单独计词”后，按 `=`／`＝` 另计附着成分的词数，语素总数不变；例如 `a-b=ke` 与 `c` 为4／2=2.000，单独计词后为4／3=1.333。统计概况显示总分子、分母和逐来源比值；空、标点与纯边界格排除，无词时显示“—”。该选项随保存条件、历史重跑和快照保留。

“词次、词形与语素统计”范围可选语言、多文本、独立库或组合。词次按词格计算，空／纯标点／纯井号不计，空句仍算一句；同一源句的多处引用不重复计算。不同词形数按整个范围去重，不能直接相加各篇的数字。完整词形保留声调、附加符号与词素边界，仅统一 Unicode 等价写法；默认区分大小写，可取消。全部语言范围按句子的实际语言分别识别词形。

“词形频率”列出次数、占全部词次比例、涉及句数和文本数；可按形式筛选和排序，点击形式或次数查看命中词格，再定位原句与前后文。频率表每页100项，来源例证每页30个词格。筛选不会改变占比的全范围分母。自然文本和诱导材料请按来源分开选择，软件不推断材料类别；独立例句不虚构文本数。

“统计对象”选择词典词条或语素，“分类标准”选择按条目分别统计、形态类、语义类、词类、形式类型、使用标签类型、语法标签分类，或任一条目字段。“筛选要统计的条目”复用侧栏搜索：可选类别／具体类，或添加多个字段条件，选择全部满足／任意一项。例如“词缀位置 → 完全相同 → 后缀”只统计后缀；也可筛出自己的某个形态类，再按语义类或构词功能汇总。已知类型和词缀位置提供分类值下拉菜单。条件针对条目自身，例句译文、例句附加层和媒体不参与条目筛选。

运行后进入“自定义条目统计”，可点击分组／条目或次数追溯原句。列出出现次数、涉及词次、句数、文本数、不同完整词形数和不同条目数。上方“范围词次／词形数／句数”以及“统计概况”“词形频率”继续表示整个材料范围；条目条件只作用于自定义统计。符合条件但没有在范围中出现的条目计入“符合条件条目”，频率表只列实际出现项，“语料中条目”给出实际条目数。未分类／未填写另成一组；同一条目有多个归属或某字段有多个值时可计入多组，各组不能直接相加。占比以符合条件的有效关联出现次数为分母；表内文字筛选不改变分母。

条目频率只使用当前有效的逐词／逐语素关联，以及实际采用且仍有效的组分分析；未采用的词典分析、整句引用、失效／待核对关联不计入。共享语素条目的已登记变体合并计数，同形但不同条目分别计；相同整词与单语素关联不重复计。区分“出现次数”和“涉及词次”，一个词格中两次出现同一语素计两次、涉及一个词次。仍可在旧记录中使用首版词根等快捷视图，新查询通过类型条件选择。导出 JSON 包含完整词频、条件、分组与例证位置，快照保存当时分类结果和来源；实时记录过期后须重跑，旧版词句快照仍可阅读。只有语码条件的组合检索仍按句显示并列涉及语言。

项目最近执行仅保留 30 条有效记录，旧实时结果失效后清理；翻页不新增。收藏存条件、快照存当时结果、研究分组存例证／笔记，彼此独立，不随最近记录淘汰。数据库释放页不代表文件立即缩小。

同音语素表使用语素／组分自己的读音和书写，不强拆整词读音。可按完整读音或默认“韵母 → 声母 → 声调”排列；语言独立“音系与排序”设置清单、顺序和匹配写法，可拖动。唯一候选可勾选批量采用，歧义和改定义后的读音重新归类仍需用户判断，普通语素关联变化不制造人工核对任务。

上下分页可各选 10／20／50 个完整韵母组或读音组及全部，两种模式分别记忆、上下同步。同条件刷新保留页码，条件／数量变化回第一页。声调名称与自选书写同行、按实际宽度接排并换行，不用斜杠／平均拉宽；具体书写缺失不拿读音补齐。悬停看读音／释义，点击右侧看语素和所见词条。

“待整理内容”保留全部符合当前检索的待整理记录。记录缺少所选书写时显示“未填写所选书写”及类型名称，保留释义、待整理原因和语素／来源词条入口；不会因为没有这种写法而隐藏已计数的记录。

“管理 → 合作者信息”是项目共用人员目录，可有多个类别、自定义字段和多种书写。文本关联多合作者及角色，旧自由文本保留待整理，不自动拆姓名或分配地点。句子可手动指定一人／多人或明确不指定；手动优先，否则继承时间轴。文本合作者不自动等于每句发言人；多轨不一致提示具体冲突。改名更新引用，删除前解除引用。

## 字体、皮肤、配色与 IPA 键盘

### 字体与配色入口

| 内容 | 设置位置／规则 |
| --- | --- |
| IPA／语素／标注／自由翻译 | 语言“信息／设置”可跟随全局字体或指定一个优先字体，缺字回退到全局；各行变体与字号比例独立，旧选择保留 |
| 普通界面 | 管理 → 全局设置 → 字体设置；字体标签从左至右回退，搜索、增删及排序后保存 |
| 书写形式 | 管理 → 项目内容 → 书写类型管理，指定字体及显示间距 |
| 附加层 | 管理 → 项目内容 → 标注层管理，可跟随全局或指定字体；保留各层的变体、字号和间距 |
| 成分配色 | 工作区域与备份设置 → 全局设置 → 成分配色 |
| 皮肤与整体文字比例 | 工作区域与备份设置中的界面主题、文字大小 |

五皮肤顺序为 **Docoid、DAWoid、暖白 · 墨蓝、夜间 · 星墨、经典 · 苔绿**；默认 Docoid，不覆盖已有偏好。字体文件支持 TTF／OTF／WOFF，可在 `font` 中扫描；TTC／OTC／WOFF2 未支持。缺字体用替代显示，不抹掉原设置。复杂 OpenType 连字／位置变体尚未专项完善。

例句各行的字体和字号在文本、独立句、词典／语素例证、调查、时间轴及右面板共用；词典主词形与列表也沿用语素字体。品牌和开发者署名固定 Junicode。

词典类型的颜色依据实际关联目标，词缀再依其登记位置；`- + =` 等分隔符不决定类型颜色，未关联／未分类用普通色。语素行、对应标注片段及右侧双标签面板同步；共享语法标签列表保持自己的颜色。

“重叠形态”依据句内已建立且仍有效的重叠关系独立着色，只标记重叠部分及对应标注，基底保持原来的类型颜色；`~` 候选与待核对关系不着重叠色。默认使用柔和玫瑰色：Docoid `#9b4566`、DAWoid `#d9a3b8`、暖白 `#91445f`、夜间 `#d8a6bd`、苔绿 `#934661`。可单独关闭、选色、恢复默认；文本、独立句、分析结果和共用引用沿用同一显示规则。

Docoid 默认中缀 `#176488`、环缀 `#276b5b`、连接成分 `#9a502d`、附着成分 `#71468e`；已有自定义配色保留。

成分配色支持总开关、每种类型单独启用和选色；关闭时跟随皮肤 IPA 色但保留已选色。各皮肤颜色分别记忆、开关跨语言，属于本机偏好。DAWoid 普通语素柔白、词缀金色，附着成分浅蓝、连接成分浅绿。保存设置后生效；字体、配色、自动备份三个设置区分别折叠并记忆。

### IPA 悬浮键盘

右下“IPA⌨”把手展开，顶部拖动、右下角调宽高、靶心恢复位置，右上收起；记忆状态并避让新增按钮／保存区，编辑弹窗中也可置顶使用。

先点击编辑位置，再按符号，插入原光标／选区。支持普通框、文本框和共享富文本；附加符号中的“◌”仅为示意，例如 n 后输入得到 n̥。沿用编辑器文字撤销；自动保存区照常保存，需要按钮保存的区域不因此变成自动保存。

分类／搜索支持符号、中英文名称和 Unicode 码位，悬浮提示显示核订中文名与实际码位。按语言收藏、最近使用及收藏拖动顺序是项目／语言隔离的本机偏好。中文名称与补充符号已按用户核订表应用，删除的旧项不再从收藏恢复。

## 保存、撤销、备份与语言交换

| 内容 | 保存方式 |
| --- | --- |
| 词条／语素、快捷编辑、例句标注 | 显式保存／取消，离开保护草稿 |
| 调查条目与本处笔记、调查笔记 | 停顿／失焦自动保存，切换与备份等操作前等待完成 |
| 区间起止时间 | 失焦或后续操作前自动保存，试听不改边界 |
| 时间轴名称 | 点击“保存名称”；排序另行即时保存 |

每语言独立撤销历史，默认 20 步，可选 10／20／30／40。一次保存／批量应用通常一步；撤销后新修改清除该语言重做分支。Ctrl+Z／Ctrl+Shift+Z 全局撤销重做，输入框优先文字编辑；显示偏好不属于语料撤销。

大搜索、自动匹配、完整时间轴、统计／检查、导入及白名单批量操作有进度和协作取消，最终提交阶段不可取消。取消回滚本次数据、引用和撤销等，可能需等待回滚完成。Windows 内存软保护 1536MiB，不是绝对硬上限；普通浏览／保存不应反复弹“正在检索关联”。

已有词条／语素保存使用事务任务；改形涉及大量例句时保留同步进度与提交前取消。改具体义项的简短释义使用读取继承，不逐句改写：通常只更新条目与规范化义项，本句覆盖保留，解除时冻结。新建条目仍直接保存。大量数据的引用保护、备份和最终刷新仍有成本。

性能须按同轮、同样本比较：一万句假语料的首次词典全部内容检索约 **19.73→15.05 秒**，全库匹配预览 **24.56→11.59 秒**；首次仍需等待。大快照打开由触及 1.5 GiB 保护阈值降至约 **175 MiB**，完整分析导出由约 **939→66 MiB**，导出主要改善内存。缓存按版本失效、查询内复用有上限；没有以这些数据承诺所有规模或界面帧率。[读取与内存实测](build/read-memory-optimization-20261022/REPORT.html)。更早逐句同步数十秒、快照约 1.2 GB 等属于已被后续实现替代的基线，见 [性能记录](PERFORMANCE_TEST_REPORT.md)。

旧项目首次使用当前源码，涉及存储精简或文本合法性清理时先建立自动快照；释放的 SQLite 页供后续复用，不自动收缩文件。两个经明确授权的正式资料迁移（义项继承、bii 形态表精简）有独立备份；其余最近功能均先在隔离副本验证，不等于获准批量改写正式材料。

### 导出和备份有什么区别

| 格式／方式 | 保留范围 |
| --- | --- |
| 原始文件 | 导入源文，不含后续全部修改 |
| Typst／Excel／Word 文本导出 | 当前文本内容与相应标注；各格式保留范围不同，不是完整项目或全部研究资料 |
| 单语言 JSON | 语言语义资料和引用，不带媒体文件，不带分析／撤销历史 |
| `.corporium` 语言包 | 语言资料、词典／语素／独立句附件，时间轴媒体可选；导入重映射 ID |
| `.corporium-backup` 完整备份 | 一致 SQLite 快照、所有语言／分析／引用／撤销及必要附件；外部时间轴媒体默认保留链接，可选携带 |
| 复制整个关闭的项目 | 同时迁移字体、模板等其他文件；复制前关闭相关服务 |

完整备份从“管理”下方生成，选择保存位置，恢复到新空项目；兼容旧 JSON 备份。字体 `font`、文件模板 `data/templates/grammar`、浏览器偏好不自动包含在完整备份中，请另迁移。主题、配色、折叠、IPA 收藏、映射等本机状态不要当作可交换研究数据；轨道颜色、笔记顺序、显示排序方案、关联 ID 与已知添加时间属于项目资料。

自动快照在 `data/backups`，默认保留 20 份，可选 5／10／20／30；不同于撤销步数。升级前先快照，成功生成后再裁剪多余旧备份。它不能替代定期放在其他磁盘的完整备份。

语言包通过“语言选项”导入／导出，不在文本导入窗口处理。导入预览后建立新语言，同名须改名，不覆盖已有语言；附属引用语言按映射导入，未携带的媒体需重新链接。调查笔记、语码、排序、形式与义项、媒体引用等随数据保存，分析／撤销历史只由完整备份保留。

## 当前边界与排错

当前提供中文／English界面和Windows x64安装包；尚未提供或验收macOS安装版。

- 词级／强制对齐、语谱图、自动识别、剪辑输出未正式实现；时间轴目前以句级区间和子层记录为主。
- 原文／IPA 局部语言着色、跨语言词典关联、笔记带入新词条未实现。高级搭配／序列／子语料对比、形态生产力、自动报告仍待规划。
- 当前句可手动采用已有完整整词分析，包括其中的切分和关联；不推测从未记录的切分，也未扩展到多句／整库批量补全或上下文预测。全库自动关联仍是另一项范围预览。
- 不执行完整 Typst，不双向同步源文件，不自动推导音变／变体条件，嵌套中缀未支持。云同步和多人网络协作不属于当前能力。
- 已有 1k／10k／50k 句及 5000 词条专项，不代表所有数据形状都即时响应。巨大结果／候选、旧 JSON 整文件恢复、断电／强杀／磁盘满等仍需加固，大项目优先完整 SQLite 备份包。
- 内容过期或“请重新预览”时重新读取当前对象，不强行覆盖。失败的自动保存保留草稿，可重试／另存副本；显式保存草稿不要依赖刷新恢复。
- 字体不对先确认所属语言，再查语言／全局／书写类型／附加层和 `font` 扫描。颜色不对先确认实际词典关联和类型，再查成分配色开关，分隔符不判色。
- 关联异常须区分真正的失效引用／附加层／语码／读音问题与已移除的旧手动状态，不把旧关系自动挪给同形单位。
- 最新源码需重启相应后端；当前0.9.01101安装包为2026-11-07同号重建，纳入主页逐语言字体等当时功能；此后仅源码修正见开头状态表。构建、自检及双语启动验证见相应发布报告；应用签名、无Python／无WebView2干净系统离线安装及真实升级／卸载不属于本轮已验证范围。

34个旧脚本已接入基线兼容入口：缺失输入按原路径恢复为独立副本，正常退出时释放未改动的恢复件，修改结果或带事务日志的文件保留。捕获的旧实现、报告与复现脚本原版均保留。新的验证工作目录放在 `build/test-materials-runs`；成功后的大工作库可清理，报告、参数和必要失败证据保留。旧路径恢复需要本机基线目录；从空环境开始可用统一生成器构造当前材料，历史精确基线仍需保存其对象文件。
