Tëlira is a fictional example language created for Corporium.

Telira.corporium-backup is a ready-to-open SQLite project (backup format v2).
Use Open Tëlira example on the desktop startup page or restore the backup into an empty project folder with Corporium 0.9.01115 or later.

Telira.corporium is a separate language exchange package. Use it to add the example to an existing project under Language options.

English edition: 573 lexemes, 2 texts, 168 sentences, and 1,221 inherited gloss associations. No media is included. Neither route replaces or translates an existing language.
