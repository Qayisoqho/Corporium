# SQLite 正文与存储约定

Corporium 0.9.01115，2026-11-15

## 存储约定

- 项目的权威业务数据保存在 SQLite。新功能用有类型的列保存字段，用有稳定身份的关系行表示引用、重复项和顺序。关联使用可验证的键，按实际查询和排序建立索引。
- 查询、筛选、统计、校验和保存优先直接操作所需的表和字段。局部编辑在同一事务更新来源、受影响的引用和撤销记录。索引与缓存可由来源重建，避免维护一份完整记录的序列化副本。
- 查找替换先筛选稳定身份，再按需要展开命中记录。提交在写入事务中重查命中和预览所依赖的修订，核对选中项后才更新关系行。工作区优先读取当前显示范围及其所需目录。
- 大批关联写入及撤销按稳定身份批量核对，优先更新所涉关系、快照子行和修订。事务内只发布一次可合并的校验代次。外部写入依然触发失效检查，涉及不同业务操作的历史按记录内容回放。
- 需要遵守文件格式、旧历史兼容或保存暂时没有固定结构的扩展值时，可以使用 JSON。新增持久化 JSON 须在开发文档说明用途、读取范围及现有关系无法表达的需求。对内需要检索、关联或反复更新的字段优先拆成关系行。
- 迁移以现有格式的项目副本验证。先备份并核对来源与关系行的内容，再切换写入和删除旧列。验证旧撤销、导入导出、引用和异常回滚。耗时报告分别记录一次性迁移、空索引准备、索引就绪检索和普通编辑。

## 四个正文来源

| 资料 | SQLite 记录 |
| --- | --- |
| 文本句 | `entries` 保存身份、文本、位置和修订号。`sentence_text_rows` 保存正文列，`sentence_word_rows` 保存有序词格。`corpus_sentence_keys` 维护按文本句读取的语言和顺序。 |
| 独立例句 | `dictionary_examples` 保存身份、语言和修订号，正文及词格使用上述两张关系表的 `independent` 来源。`independent_links` 保存关联和选择身份。 |
| 词条和语素 | `lexemes`、`morphemes` 保存身份、词形或语素形式与修订号。`dictionary_value_rows` 以有序类型化行保存义项、变体、构词、变形表和扩展定义。`independent_dictionary_keys` 保存用法、义项及形式的引用键。 |

四张来源表的 `body` 列已移除。词条同形号排序索引使用 `lexemes.homonym_number`，句子检索索引读取正文标量、稳定身份及词格。句子检索范围以 `source_language` 和 `grammaticality` 列保存。正文写入向相关触发器提供变更范围，缓存根据实际变化入队。

独立例句的词形和标注直接读写 `sentence_word_rows`。`independent_words` 只维护例句、位置和标注身份，已删除整格 JSON 副本 `source`。迁移先备份，再逐格核对类型、内容及身份，并在同一事务重建身份表。旧 SQLite 项目包恢复时执行同样的校验。[验证与实测](WORKFLOW_BENCHMARK_20261112.md#独立例句词格去除整格副本2026-11-14)

`independent_word_overrides` 直接保存冻结词格的词形、标注和身份。`independent_override_values` 用有序类型化行保存其余字段与对应来源，原 `source`、`word` 列已删除。写入正文的独立例句 `gloss_frozen` 项保存在 `independent_frozen_values`。`independent_links` 的分段快照列保存全词及关联单元的词形、标注和脱离状态。`independent_link_fragments` 保存按序排列的偏移和片段文字，少数旧结构使用 `independent_link_ref_values` 保留额外的类型化字段。只有现有交换格式、历史回放和个别仍需词格对象的派生读取临时组装这些值。关联和子行在同一事务更新，项目迁移核对旧值及绑定指纹后切换。[回归与前后计时](WORKFLOW_BENCHMARK_20261112.md#独立例句冻结标注与分段快照2026-11-14)

首次替换预览使用 `sentence_word_form` 和 `dictionary_typed_lookup` 缩小候选范围。自动关联从 SQLite 读取词形、语言和稳定身份，只展开可能匹配的词典定义。预览可以在进程内按已校验的来源修订复用，缓存失效后重新核对。两个索引随项目初始化建立，更新由 SQLite 维护。[准备及操作计时](WORKFLOW_BENCHMARK_20261112.md#首次替换预览与自动关联2026-11-13)

自动关联的 `auto_match_*` 投影按实际语言、规范词形与完整标注查命中。标注键含语法标签与固有特征，使用有长度边界的二进制键。来源位置、词典用法、义项和形式身份使用类型化列。正文或定义变更时，SQLite 触发器在同一事务记录受影响身份，预览按这些身份更新索引。关联提交与撤销直接读取当前关联状态，匹配键无需随关联重建。可携带的项目备份删除派生索引，恢复后首次使用时重建。[匹配与回放实测](WORKFLOW_BENCHMARK_20261112.md#自动关联匹配索引与批量回放2026-11-13)

普通词典全字段检索按语言和目标类型保存字面值、定义与例证的显示名依赖。变动按稳定身份标记，更新相关定义、例证和手工附加标注。附件检查通过所有者、媒体、变体、发言人引用缩小范围，校验证明失效时进行完整核验。字面索引和校验待处理记录可重建，并随便携备份剔除。[保存与全字段复测](SCOPED_MEDIA_DICTIONARY_20261115.md)

空全文投影的普通查询从词典标量、正文列、词格和手工标注的来源 B-tree 索引筛选，再核对命中的定义及有效继承标注。没有新增权威 JSON；现有开放扩展使用原匹配器解释，扩展表达式索引及临时增量队列仍可包含其原编码，这是派生检索辅助，不能成为第二份正文来源。冷查询缓存有容量和范围上限；来源、绑定、手工层及外部 SQL 的代次在事务内更新，回滚不能复用已撤回的查询状态。便携备份剔除这些辅助索引与队列。必须分别报告来源索引安装、空投影首次查询、新查询及编辑后的增量查询，不能把准备时间移到启动后便称首次成本消失。[实测与限制](COLD_SEARCH_STARTUP_20261115.md)

语法标签用量按句子、语言和标签保存可增量汇总的频次。项目交换和备份恢复时从关系行重新准备。[首次及增量计时](WORKFLOW_BENCHMARK_20261112.md#词格替换全字段检索与标签用量)

高级检索选项目录在 `material_search_option_*` 记录各条目提供的检索字段和依赖。来源、书写类型或分类变化时，只标记已准备范围中的受影响条目。目录、字面值索引和分页缓存可重建。近期统计重复运行通过 SQLite 引用复用同一份不可变的压缩结果，保留独立运行记录。便携项目备份仍为每次运行导出完整结果。[性能对照](PERFORMANCE_RECOVERY_20261112.md)

`source_schema.py` 在首次打开旧项目时验证已有关系行并补齐缺行。应用先创建完整 SQLite 快照。在同一迁移事务中按稳定身份比对原正文、切换索引与触发器、删列，并执行 SQLite 完整性和外键检查。校验出错时撤销迁移事务。旧的正文与撤销历史仍可从迁移前快照恢复。

## 交换与兼容

Typst、Word、Excel、语言 JSON、语言包和原版项目 JSON 继续使用原有交换格式。旧撤销记录中的序列化正文在回放时读入，新撤销记录用结构化前后值恢复关系行。完整 SQLite 项目包携带关系正文和撤销历史，使用 `corporium-sqlite-backup-v2` 标识。当前源码也可恢复 `v1` 项目包。打开已迁移项目或恢复新版 SQLite 项目包可使用 0.9.01115 安装版或包含此迁移的源码；不能用旧 0.9.01108 安装包编辑。

部分扩展属性、正文语码快照、分析结果、项目设置和撤销记录仍采用 JSON 编码。个别需要文档形状的旧查询从关系行临时组装值。其余范围的历史盘点见[例证读取与存储盘点](RELATIONAL_EVIDENCE_READS.md)。

## 本机项目迁移

2026-11-12 分别备份并迁移了本机正式项目与 Tëlira 工作项目。两次均先在一致副本上核对正文和业务表，再在确认源文件未变化后替换原数据库。正式项目的 631 条文本句、6 条独立例句、4,158 个词条、295 个语素和 100 条撤销记录保留。Tëlira 的 2 篇文本、168 条文本句、573 个词条、1,221 条继承关联和 4 条撤销记录保留。两库均通过完整性和外键检查，迁移前快照分别留在各自的 `data/backups`。

2026-11-16，Tëlira 工作库跟进独立例句关系结构。副本及工作库逐表对照正文、身份与四条原撤销记录；副本另做撤销／重做。当前源码的「打开 Tëlira 示例」优先恢复 `Telira.corporium-backup`，其中的 `project.sqlite3` 是关系正文 v2 快照。启动资源缺失时继续支持旧语言包；损坏则报错并保留当前项目。`Telira.corporium` 仍是向现有项目添加 Tëlira 的交换包，ZIP 内的 `language.json` 只作交换，不是项目正文存储。两种资源已核对英文内容和关联，并同步主目录与本地公开副本。本轮未重建安装包。

2026-11-14 正式库在核对备份后，在一个事务中移除 `independent_words.source` 并迁移冻结标注和分段快照。对照 62 张业务及来源表，保留 4 个语言、8 篇文本、631 条文本句、6 条独立例句、4,158 个词条、300 个语素、11 条独立例句关联和 100 条撤销记录。迁移写入 7 条关联片段，SQLite 完整性和外键检查通过。正式库可用 0.9.01115 或兼容开发版打开，迁移前快照位于本机 `data/backups`。

## 隔离库核验与计时

复用密集库的 10,000 条文本句、1,000 条独立例句、2,014 条词条、1,000 个语素，以及上限库的 50,000 条文本句、50,000 条独立例句、50,000 条词条和 5,000 个语素。逐条核对旧正文后，确认两库实际移除四列，SQLite 快速完整性和外键检查通过。密集库的 132,000 个词格及 501,467 个词典值行、上限库的 975,000 个词格及 1,725,518 个词典值行保留。混合检索首页和第九页、统一例句库及独立例句筛选的结果总数、所测位置和显示文本摘要在删列前后相同。

## 保存时重叠推断（2026-11-15）

新增保存逻辑读取当前语言标签和已切分词格，复用既有稳定身份与重叠分析扩展，不新增持久字段、不双写关系。扩展保存位置、旧交换及撤销兼容范围见[实现记录](AUTO_REDUPLICATION_20261115.md#存储范围)。
