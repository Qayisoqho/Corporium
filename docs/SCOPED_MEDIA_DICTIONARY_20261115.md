## 同轮复测

复用密集库和十万句库。密集库有 11,000 句、2,014 个词条、1,000 个语素，十万句库有 100,000 句、50,000 个词条、5,000 个语素。原材料无条目附件。两版各自在隔离副本中挂接库内已有录音，分别加入 2,200 和 6,000 条附件关联，包含词条、指定变体和独立例句。样本词条带两个附件。计时走应用保存、后台词典检索和撤销入口，包含提交及响应，单位为毫秒。

| 操作 | 密集库改前 | 密集库改后 | 十万句库改前 | 十万句库改后 |
| --- | ---: | ---: | ---: | ---: |
| 首次全字段检索，索引从空开始 | 12,153 | 12,312 | 27,654 | 26,767 |
| 索引就绪后重复请求 | 33 | 35 | 26 | 28 |
| 改一条详细释义并保存 | 764 | 92 | 1,736 | 67 |
| 保存后首次查询新释义 | 4,623 | 69 | 17,013 | 45 |
| 撤销 | 708 | 84 | 44 | 39 |
| 撤销后首次查询该释义 | 4,495 | 66 | 16,090 | 47 |

首次检索与原查询的立即重复各一次。其余各做三轮，表列中位数。两版以同样方式清空词典、关联例证和稀疏附加标注的相应索引，保留已有源库和共用字面值，磁盘缓存为系统当时的状态。计时起点为打开项目后的请求，终点为返回结果。前端行为另作回归检查，浏览器绘制耗时未纳入表中。

十万句库的首次准备中，词典字段约 15.8 秒，关联例证值约 8.0 秒，例证字面索引约 1.0 秒。密集库的词典字段约 4.1 秒，关联例证值约 7.6 秒。首次准备仍需组装当前范围内的词典定义和已关联例证。现有项目升级后，每个语言和检索类型首次准备其增量记录。保留索引用新进程再查，密集库约 46 毫秒，十万句库约 55 毫秒，均没有重新组装定义或例证。密集库本轮空索引首次耗时略增，十万句库约降 3.2%。磁盘状态不同的试跑波动较大。

## 工作量与校验

| 诊断计数 | 密集库改前 → 改后 | 十万句库改前 → 改后 |
| --- | ---: | ---: |
| 保存时核对的附件 | 2,200 → 2 | 6,000 → 2 |
| 保存时媒体校验读取材料定义的次数 | 2,200 → 1 | 6,000 → 1 |
| 保存后再次检索组装的定义 | 2,014 → 2 | 50,000 → 1 |
| 保存后再次检索重读的例证正文 | 0 → 0 | 0 → 0 |

密集库样本的详细释义也是一个被引用的显示名，因此另一个有依赖的词条也更新。基线仍复用已准备的例证正文，同时重新遍历该检索范围的关联身份。新路径在 SQLite 记录变化的定义、反向关系、关联例证和显示名依赖。首次检索后，附件、录音名称、分类和书写类型等变动只更新实际依赖的检索记录。附加标注的字面值先筛选命中，再核对标注层、语言及词格身份。复用原检索文本投影和分页排序。

附件检查通过稳定的对象、录音与发言人身份定位变动，复用同一对象及录音的读取。条目变体、关联对象、媒体元数据或发言人删除影响附件时，照常检查语言、有效音轨、时段及引用。校验证明失效时完整核验。变更记录和派生待更新项与业务保存处在同一事务，旧项目和备份恢复支持重建。

两库比较首次及重复查询、每次保存后新释义的命中、撤销后旧查询的完整响应和条目正文。每一步核对有序附件关联及变体身份。四个隔离副本均通过快速完整性和外键检查。回归还覆盖了附件说明、录音名称和直接关系行更新、反向基本词条、关联例句新增和撤销、附加标注、继承标注、旧项目迁移、旧撤销、备份和语言包。

主目录通过 126 项相关后端测试，本地 `github/` 通过 52 项。两份源码分别通过 15 项词典前端行为检查和 816 条样式审计。
