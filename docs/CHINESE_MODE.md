# 汉语模式与语素生成基本词形

2026-11-15 核对：含 11-11 的共用语素表、重叠关联同步及单行连接文字修复；随 0.9.01115 发布。历史计时仍保留当轮口径。

汉语模式是按语言保存的录入预设，适用于由连续语素组分生成基本词形的资料。在「管理 → 语言」选中语言，进入「录入与显示」可将「汉语模式 / Chinese mode」与默认书写列一起保存。既有词条通过「词形来源 / Headword source」选择一份分析，或使用「独立词形 / Independent headword」。

## 录入与编辑

完整编辑中的汉语模式区位于“条目信息 / Entry information”之后、义项／形式等导航标签之前。词形来源与连接文字左右并排；窄内容区将标签放到对应控件上方，更窄时自然换行。条目信息的标签与控件同行对齐，同形号输入框稍加宽。

每一行对应现有构词分析里的一个稳定组分。表格显示语素关联搜索、形式、读音和自定义书写列。所选语言的默认书写列和分析中已有的书写类型在打开时显示。可临时增加书写列、添加和移除组分、通过排序柄调整顺序。已有简短释义可在「构词分析详情 / Analysis details」中编辑。

每行的搜索框、候选列表、关联方式及具体变体沿用原快捷编辑控件。关联共享语素后，形式、读音和书写保留原只读规则；解除关联后可编辑本地草稿。完整与快捷编辑共用同一个表格控制器及原组分节点，切换视图不另建一份分析。汉语模式的快捷编辑直接输入语素，点击保存时基本词形就是所选分析的叶组分拼合结果。

↑／↓在同一分析的同一列移动，包含关联搜索框；←／→只在光标位于文本起止边界且没有选择范围时切换相邻可编辑字段。目标文字自动选中，隐藏、只读、禁用或缺失字段跳过，不跨分析。输入法组合、修饰键和原生下拉选择保留自己的行为。普通语言快捷编辑的搜索框行为与释义列保持原样。

连接文字留空时直接拼合，也可以输入空格、连接符等单行文字。保存和导入会拒绝换行，包括 U+0085、U+2028 和 U+2029。旧版已保存的这几种分隔符可按原样读取，编辑对应词条时请改为单行连接文字。基本词形预览实时更新。保存时后端重新计算词形，然后执行同形词检查及现有语素整理。未明确选择且存在同形候选的组分，沿用原有“核对同形语素”流程。所有词条、语素、组分关联和派生变动在同一事务提交，撤销／重做使用原入口。

完整与快捷编辑共用同一份分析草稿，分格通过稳定组分身份连接原控件。来源分析与默认展示分析分别记录。删除来源分析或清空全部有效组分后，须选择有效来源或独立词形才能保存，切回独立词形保留当前完整形式。已有不连续多部分形式可在独立词形编辑中处理，第一版生成模式采用明确的连续组分形式。

语言开关控制新词条默认值。关闭开关后，已保存的生成词形继续按照自己登记的来源维护。已有独立词形在开启语言模式后仍保持独立，研究者可逐条转换。

## 数据与维护位置

- 语言偏好保存于 `languages.metadata.chinese_mode`，类型为布尔值。
- 词条的逻辑字段 `headword_source` 保存 `analysis_id` 和 `joiner`，在 `dictionary_value_rows` 中以类型化关系行持久化；不再写入已删除的 `lexemes.body` JSON 列。接口与交换对象仍使用原字段形状。空值表示独立词形。旧数据缺少此字段时沿用独立词形。
- `chinese_mode.py` 规范化来源、解析指定分析的叶组分，并在现有写入路径维护物化的 `lexemes.headword`。列表、搜索、自动关联和同形词索引继续读取该字段。
- `lexicon.py` 在选择语素具体形式后计算基本词形。`dictionary_targets.py` 和 `morpheme_registry.py` 的共享内容写入同步重算受影响词条。
- `web/chinese-mode.js` 协调中英文来源选择及完整视图中的原分析位置；`web/quick-edit.js` 共享默认书写设置，`web/quick-edit-rows.js` 渲染两种视图的同一份语素表。原分析、语素选择和保存入口继续复用。`web/ui-standards.css` 提供文字与控件角色，布局规则位于 `web/workbench.css`。

导入、复制和备份保留来源及稳定分析身份。外部导入错误来源、空格、失效形式或不一致基本词形时按既有验证入口报错。数据结构或完整校验规则变化时维护 `save_validation.RULES_VERSION`，派生缓存按现有真实变动机制失效。

## 关联、搜索、替换和统计

词形来源以组分形式为输入，共享语素身份及具体变体继续独立记录。普通共享形式修改仍经过已有词典形式同步流程，相关标注、词频及同音表按实际变动更新。原始导入文本、IPA和自由翻译按原有约定保存。首次从相同分析采纳生成来源时，保留例句中的既有实际形式。

同一个词格可以同时关联整词和组分。共享语素改名时，若按各组分更新得到的词形与整词更新一致，文本句和独立例句均合并为一次写入，并保留句中已有的 Typst 标记和语素边界。部分交叉或结果冲突仍会拦截并回滚整次保存。[同步与局部校验](SCOPED_SAVE_VALIDATION.md)。

生成词形可在正常词典检索中命中。内部来源标识不成为“全部内容”检索材料。直接替换生成的基本词形会给出中英文提示，可改其来源组分、替换关联语素形式，或先改用独立词形。独立词形及其他字段的替换沿用原规则。

同音表通过原 `hp_dirty` 和来源身份更新。统计继续区分词条、语素、词次和词形，新来源字段不增加研究材料或计数单位。回归覆盖共享形式替换后当前统计与实际标注内容一致，以及撤销／重做恢复旧结果。

## 本次原项目转换

用户授权对 `data/corpus.sqlite3` 中的绍兴稽东话开启模式，并把已有有效语素关联的词条转换为生成词形。转换按实际存在的分析与组分身份判定。

共 161 个词条登记生成来源，3,722 个无活跃语素关联的词条保留原词形。161 个中有 3 个基本词形按现有组分拼合更新。两条指向已删除组分的历史关联保留原记录。此次操作具有独立撤销步骤“启用汉语模式并转换稽东话词形”。

转换前制作 SQLite 完整在线备份，路径记录在本机 `build/chinese-mode-20261110/qa_real_migration_result.json`。该文件还保留三个词形的前后值，仅作本地研究核对。正式事务在提交前核对实际变更范围，其他语言、未转换词条、例句正文及各类关联均作逐表指纹对照。副本演练经过正常撤销和重做，并检查新词形搜索和同音表索引／扫描一致性。
