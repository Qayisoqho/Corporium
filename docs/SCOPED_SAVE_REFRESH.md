# 保存后的局部刷新

## 词典语言切换与复合编辑（2026-11-12）

切换语言时，词典加载之前还会更新语料导航。旧查询先联结句子和文本元信息，再按文本计数。十万句库的语言切换里，单个 `texts` 请求在首轮耗时约 0.62–0.66 秒。现在每个文本通过 `entries_text` 的覆盖索引统计句数，正文、文件夹和导航顺序由原入口保持一致。

同一词条同时修改词形、完整释义和备注时，原来会落到全库词典检查。隔离计时中，保存事务约 18.87 秒，`validate_links` 约 18.74 秒。现在在可信 SQLite 快照内检查受改条目、书写类型、同形组、移除义项或形式的入向选择及新增的构词或条目关系。新增边只检查可达路径。组件引用从类型化关系行查找。需要复核或失去可信凭据时，仍运行完整检查或明确确认。保存事务与撤销记录一起提交。

已提交的回执确定详情、词典列表、义项与变体各自需要更新的范围。完整释义和备注的普通编辑复用当前例证。简短标注改变时，检索索引只标记受影响的继承记录。界面按当前页的关联 ID 读取有效标注和撤销状态，只替换变化的词格，并保留原句卡、媒体控件和复制身份。会改变分词结构、例证归属或当前分页的编辑继续走相应的完整读取路径。

性能测试复用已有十万句库和密集关联库。上限库含 50,000 条文本句、50,000 条独立例句、50,000 个词条和 5,000 个语素。密集库中测试词条有 10,000 条文本关联和 1,000 条独立例句关联。从实际点击计时，等待请求、保存任务和字体结束、连续 150 毫秒无相关页面变化，再取下一动画帧。每次保存后用正常撤销核对词条内容和稳定身份。原始时间线位于本地 `build/dictionary-latency-20261112`。

## 既有词格、词形与语素关联（2026-11-11）

服务器依据已通过的结构校验和保存事务的实际变动判断能否返回局部更新回执。词格保存复用正常读取的句卡结构，带回已提交的词格、标注层、词典关联和警告。文本语料只更新该句，独立例句库更新该句在当前页的各个位置。筛选结果、警告筛选和语码统计变化仍会重新查询当前结果。词典详情内编辑例句时重新读取对应来源的例证页。

词形修改更新词条标题及涉及的变体显示。影响匹配或排序时重新查询词典列表，保留当前详情和其他面板。语素关联更新当前词条的构词分析和语素链接，并保留原分析展开状态。需要同步例证内容时，只读取受影响的例证来源。项目修订号不匹配或修改范围超出回执可证明的内容时，沿用现有刷新流程。

## 保存后如何更新

普通词典页保存已有词条的备注后，界面使用服务器返回的词条更新详情中的备注、记录修订号和撤销按钮。编辑、复制、删除与例证操作所引用的词条对象一并更新。侧栏当前页和已经勾选的批量操作记录也取得新修订号。带有查询文字或高级条件的词典列表重新计算匹配和分页。

独立例句库保存已有句子的译文或备注后，界面使用正式保存的字段重新渲染这句话在当前页的每个出现位置。渲染复用原有标注、附加层、媒体、音频和格式化复制逻辑。每个出现位置有独立的复制身份，并保留原句卡和所在例句组的节点，以便恢复阅读位置和键盘焦点。其他句卡及其已经加载的媒体控件继续可用。例句库处于检索或其他内容筛选状态时，重新查询当前结果，核对组内命中、计数和分页。

## 回执和版本核对

可以原位更新的界面随保存提交自己正在展示的项目修订号。服务器在持有写锁时核对这个修订号和已有的校验记录，在同步、清理、校验及撤销记录处理完成后再检查实际变动。只有一个已存在的目标记录发生了上轮定义的等价默认值和文本字段变化，才生成包含记录身份、前后修订号、项目修订号及正式字段值的回执。直接保存和后台词条保存都在成功提交后附上回执。

界面重新读取撤销状态，核对当前语言、原视图、选择、查询条件和提交后的项目修订号，再更新当前记录。其他窗口发生写入、来源状态失效、结构或多条记录发生变化时，应用按现有入口重新读取视图。其他工作区再次打开时按项目修订号检查内容。首次完整校验和旧例句首次补入分析字段也可能走完整刷新。

## 测量方法

复用现有的33词条小库和5,000词条、5,000语素、50,000文本句、5,000独立例句的大库。普通计时从点击“保存”开始。第一次出现已提交的内容和可再次调用的编辑按钮时，记录可续编时间。页面稳定时间还包括响应体读取、任务结束、字体就绪、动画帧和连续150毫秒无页面变化，以覆盖媒体控件的延迟加载。正式轮次另观察250毫秒的后续请求。

改动前与改动后的普通测量均为中英文，各预热一次，随后重复三次取中位数。每次使用正常撤销核对原始记录的文字、身份和研究结构，修订号按正常保存与撤销机制增加。测量使用原有功能测试材料，备份、源码检查和交互验证均在隔离目录进行。

## 功能核对

两份源码均通过词条备注新增、清空、连续编辑、侧栏选择与后续修订号检查。实测备注查询的结果移出、另一窗口写入后重新读取、同一句在多个组中的同步显示、各处独立复制身份、再次打开编辑器取得最新译文、按译文筛选的组内结果，以及撤销／重做恢复匹配。专门的回归检查还覆盖在网络请求期间切换语言、提交后又有其他写入、外部直接写入和保存中的附带更改。

便携备份的行数与内容检查已按现有备份格式排除词形搜索派生表和校验状态表。恢复时继续逐表对照研究记录和历史，并检查错误校验和及重复恢复。
