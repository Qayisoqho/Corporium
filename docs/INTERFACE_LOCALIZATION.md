# Corporium 中文／English界面

在“工作区域与备份设置 → 全局设置 → 语言设置”切换；项目选择页也提供语言入口。偏好保存在本机，应用内置同一套双语界面。

切换前提交自动保存；未保存的例句草稿需要先保存／取消。切换后恢复工作区、筛选、页码和阅读位置。已有研究内容、语言名称、词类、备注、文件标题与引用不自动翻译；英文界面中新建的内置调查提纲可使用英文默认标题。

## 维护

作者界面文案在`web/i18n-messages.json`，前端使用`CorporiumI18n`，后端通过`ui_localization.py`在显示边界翻译。新增文案使用当前消息目录或现有`ui(中文,English)`接口，保留现有核订术语，避免先生成中文DOM再对整页内容扫描替换。

语料与自定义数据不能进入界面翻译；带参数文案保留参数顺序及任意用户文字。语言重载必须等待保存并处理草稿，不能为切换清空研究资料。历史一次性全源转换脚本不属于公开副本的常规维护流程。

[当前副本验证](VERIFICATION.md)说明实际执行范围；检查界面时应覆盖两种语言、主题、放大字号、窄窗及编辑／复制操作。
