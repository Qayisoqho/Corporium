# Word 标准文本交换

Corporium 的文本导入、导出可选择 **Word（.docx）**。这一版用于标准文件与新文本交换，不覆盖库中已有文本，不是项目备份，也不提供 AI 识别。

## 使用流程

1. 在文本侧栏点击“导出”，选择 Word 和当前语言的一个文本。长句按内容宽度分段；“排版选项”可设置每段最多词格数。
2. 没有现成文本时，在 Word 导入窗口下载空白模板。无需在用户电脑上安装 Word 才能由 Corporium 读写 DOCX。
3. 用 Word 编辑例句范围内的 IPA、语素／标注表、翻译和备注。未用词格可删除整列；空标注格仍须保留对应单元格。
4. 导入时选择标准 DOCX。系统先显示分句预览，尚未创建文本。
5. 点击词格间的“↵”拆句，或点击“与下句合并”。IPA、翻译、备注可以展开修改。字段、标题、标注层映射改变后需要更新预览。
6. 确认导入后创建新文本，整次导入可以撤销、重做。原文本保持原样。

旧 `.doc` 文件需先另存为 `.docx`。任意空格排版、扫描件、文本框或没有例句范围的旧文件，不属于这一版的标准导入范围。

## 句界和长例句

每句有一个 Word 内容控件，名称为“例句范围（可含多段词格表）”。编号、IPA、多个词格表、翻译和备注均在此范围内。控件的边界不打印；改变字体、自动分页或表格数量不会改变句子归属。

每段词格表至少有“语素”和“标注”两行，每词一列。两行必须具有相同单元格数。单元格内自动换行、换页不是新词或新句。不同段落的词格依次接续，不要求各段列数相同。

增加同一句的续段时，将完整的语素／标注表复制到当前例句范围内；新增句子时复制完整的例句范围控件，包含编号、IPA、表格、翻译与备注。只复制内部表格不会创建新句。显示编号用于阅读，不负责识别句界。

拆句不会猜测 IPA 和译文的对应位置：包含原句起点的部分保留原来的句级字段，后面的部分可人工补填。合并时按原顺序保留词格，句级字段以换行连接。空句也保留；拆分和合并均不静默丢弃文件中的词格。

## 保存的内容

- IPA、原文、词形／语素、当前有效标注、自由翻译、备注，以及映射到当前语言的附加层。
- 词级附加层随对应词格移动；句级附加层随原句起点保留，合并时换行连接。
- 上下标通过 Word 原生字符格式保存，重新读取恢复 Corporium 的上下标记法。字体比例沿用语言设置，文字本身不转换成 Unicode 小型大写字符。

导出的是当时的有效释义。导入为新的未关联文本，因此这些释义是新文本自身的标注，不会重新关联词典，也不改原词条或原句的继承／覆盖模式。词典关联、人工形态组合、重叠关系、语码、时间轴和研究引用不在此交换格式的保留范围，完整交换请使用语言数据包或项目备份。

源文件带附加层时，需要选择对应的本语言层；同一身份或唯一同名、同锚点的层会预选。没有对应层时可先在管理中创建，再重新打开导入；也可明确选择“不导入此层”。程序不会按跨语言的旧层 ID 写入内容。

## 核对与限制

预览每页20句；超长句先显示200词格，可展开其余内容。预览分组及字段签名在导入时重新核验，标注层发生变化也需要重新预览。创建文本、句子和附加层单元格在同一可撤销事务中完成，失败整体回滚。

标准表不支持合并单元格、嵌套表、图片／文本框／对象或正文脚注引用。文件有尚未处理的修订时，先在 Word 中接受或拒绝修订。例句范围外的未知内容、字段外的额外文字、缺少配对行等会明确报错，不作为成功导入后悄悄省略的内容。

单文件最多14MB，解压内容最多100MB；最多20,000句、200,000词格，单句或合并后单句最多5,000词格。大文件请先拆分文本。导出布局是生成时的分段；后来在 Word 中改变字体或页宽后，可调整表格分段，但普通表格不承诺像网页词格一样自动横向重排。

## 开发格式

`word/document.xml` 中每句使用 `w:sdt`，其 `w:tag` 为 `corporium:sentence:v1`，内部普通表格按文档顺序接续。句级内容使用 `corporium:field:ipa`／`translation`／`notes`／`original` 控件；附加层使用 `corporium:layer:<源层ID>` 标签及自定义 XML 层定义。

读取通过命名空间发现自定义 XML，不依赖其文件名；段落样式同时解析样式定义中的名称，兼容 Word 另存时改写部件名和内置样式 ID。导入身份全部新建，文件里的控件不作为本地数据库外键。

文件只在本机解析，不执行宏、外部关系或文档程序。读取一次后将规范化结果暂存到当前项目范围的令牌中，预览只重建文字与分组，不重复分析全部语素；正式导入才执行分析。导出批量读取词格身份和附加层，避免逐句重复查询。
