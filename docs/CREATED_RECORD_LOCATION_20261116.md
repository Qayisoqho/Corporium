# 新建内容的分页与定位（2026-11-16）

发布补记（2026-11-16）：本文功能已纳入 **0.9.01115 同号重建安装包**。[本次构建与核验](REBUILD_0.9.01115_20261116.md)。下方“仅源码／未打包”和测试数字保留开发当轮事实。

## 行为

- 在文本中新增句子，先清除正文筛选并进入该文本末页，再显示本地草稿。保存后按新句子的稳定身份查询实际页码，重新读取分页结果、句数与文本列表，再显示并聚焦新句。跨页边界、空句和句序存在间隔均适用。
- 新建词条或语素，保持当前排序及每页条数，定位到新条目所在页并显示详情。现有搜索条件能命中新条目时保留；否则清空检索条件后再次定位。分类排序仅展开新词条的祖先分支；“全部”及长列表会先挂载对应条目，等待行高测量后定位。
- 新建独立例句按当前添加顺序定位。词条、语素内部的独立例句分页，以及调查条目内新建例句的末页同步处理。例句组和轨道继续使用各自保存回调；弹窗内新例句优先在当前弹窗聚焦。
- 既有条目的编辑继续保留原阅读位置；保存失败保留草稿。新记录的显式定位不再被旧草稿的滚动恢复覆盖，异步返回时检查当前语言和工作区。

## 实现与存储

`entry-page` 只读查询所属文本、稳定句子 ID 与排序位置，按实际行数定位，不把句序直接当分页偏移。词条、语素和独立例句列表支持 `focus`，沿用原有过滤与排序，对稳定 ID 序列定位后读取目标页；无匹配返回 `focus_found: false`。独立例句的分页计划缓存不包含焦点参数，超出缓存范围时使用窗口查询定位。

没有新增持久字段、存储格式、JSON 副本或研究数据迁移。原有查询需要的旧格式兼容范围未扩大。正式项目未改写，验证资料全部位于隔离预览目录。版本保持 0.9.01115，安装包未重建。
