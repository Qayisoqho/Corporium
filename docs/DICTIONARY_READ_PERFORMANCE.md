# 词典读取性能：第一阶段（2026-11-09）

2026-11-15 发布补记：本文为历史实现／测量记录，已完成代码纳入 0.9.01115；当前发布范围见[发布核验](RELEASE_0.9.01115.md)，最新查询与启动测量见[后续报告](COLD_SEARCH_STARTUP_20261115.md)。

版本保持0.9.01108。本轮优化源码中的词典列表、空关联选词和主词形字段查询；安装包仍是此前的同号发行，尚未包含本轮优化。

## 改动范围

- 空的`scope: entry`查询直接分页，不再为整库构建搜索文档；仍验证匹配设置，未知字段、类别和复杂条件沿用完整验证与搜索。
- 默认词典列表使用与`NOCASE`、原始同形词下标及rowid次序一致的复合索引。统一选词先读取词条／语素的排序键和身份，确定当前页，再经原有读取接口组装内容。完全相同的排序键显式保留词条在语素之前的次序。
- 侧栏摘要在SQL中只投影同形词说明及词类名称，不向Python传递完整研究正文。详情、关联框和导出继续保留原有完整字段、修订号及目标身份。
- 主词形／语素形式的精确、前缀、后缀和包含匹配复用`search_keys.Values`的NFC、Unicode casefold、B树及可选FTS5三元组索引。由匹配值定位条目身份，再分页读取正文；`%`和`_`仍按字面文本匹配。
- 新增的`dictionary_form_search`与`dictionary_form_dirty`均为可丢弃的派生数据。只在身份、语言或主词形变化时标记，随读取按需更新；普通正文编辑不重建词形键。SQL触发器覆盖保存、外部写入、删除、转换、撤销和重做，同一事务内发布。共享值回收保留其他索引仍在引用的值。
- 快照导出移除这些派生表及触发器，初始化时恢复。索引缺失、只读或准备时遇到写锁争用时，保留完整搜索路径。未修改研究材料结构、JSON交换格式、冲突检查、继承同步、撤销机制或网页样式。

## 复用材料与测量方法

直接复用既有隔离材料，没有重新生成压力材料：

| 既有数据库 | 词条 | 语素 | 语料句 | 独立例句 |
| --- | ---: | ---: | ---: | ---: |
| `build/layer-performance-20261026/after-10000.sqlite3` | 1,003 | 1,000 | 10,100 | 1,003 |
| `build/performance-after-20261016/synthetic-50000.sqlite3` | 5,000 | 5,000 | 50,000 | 5,000 |

先用修改前的当前版本初始化旧隔离库，再保存基准；之后复用同一个库及业务记录。性能脚本不生成数据，拒绝打开`build/`以外的库；后端检查与网页预览也分别限制在隔离目录。正式`data/`、`github/data/`未以SQLite打开。

每项操作先执行一次，再以三次复用索引的读取中位数比较；各次重新建立数据库连接，顺序测量。耗时覆盖后端读取，序列化单独记录；JSON解码计数和SQL跟踪在额外执行中采集，避免计数器影响耗时。这里的“首轮”不代表清空操作系统磁盘缓存；另单独清除可重建的词形键，记录首次准备索引的查询成本。

本机逐项测量、返回内容指纹、查询计划与冷索引结果见`build/dictionary-read-performance-20261109/`中的`before-1000.json`、`before-5000.json`、`after-1000.json`、`after-5000.json`、`public-5000.json`及`cold-exact-5000.json`。

## 保持的行为与验证

新增`tests/test_dictionary_read.py`，以完整文档匹配器作为对照，检查Unicode规范化、大小写、空白、字面符号、布尔组合、全部语言、分页及全部条目、添加时间、同形词、只读回退、无FTS、快照重建、外部写入、跨语言移动和撤销重做。摘要不得解码完整研究正文；空选词不得构建整库搜索文档。

## 边界与下一步

本轮没有为“词条全部内容”的非空查询建立新的正文投影。正文、变体、释义、关联例句、动态字段、类别或自定义字母排序仍采用既有完整路径。包含数千条命中的宽泛词形查询仍须处理匹配身份并排序；统一词条／语素列表也仍可能对窄排序键使用临时排序。不能据此承诺所有操作、十万词条或深分页均为个位数毫秒。

继续优化前应另测这些实际路径的耗时占比；如果正文搜索仍是主要等待，再扩展可增量更新的搜索投影。此阶段不引入整库正文缓存，也不重写研究数据为全关系模型。

## 复测

对已有隔离材料执行；首次升级旧测试库时才添加`--initialize`：

```powershell
.desktop-venv/Scripts/python.exe -B tools/benchmark_dictionary_reads.py --database build/performance-after-20261016/synthetic-50000.sqlite3 --output build/dictionary-read-performance-20261109/recheck.json --runs 3
.desktop-venv/Scripts/python.exe -B tools/benchmark_dictionary_reads.py --source-root github --database build/performance-after-20261016/synthetic-50000.sqlite3 --output build/dictionary-read-performance-20261109/public-recheck.json --runs 3
.desktop-venv/Scripts/python.exe -B tools/benchmark_dictionary_reads.py --database build/performance-after-20261016/synthetic-50000.sqlite3 --output build/dictionary-read-performance-20261109/cold-recheck.json --only headword_exact --reset-form-keys --runs 3
```

`--reset-form-keys`只清除并重建词形派生索引，不生成、替换或复制研究材料。
