## 保存行为

`auto_reduplication.py` 在句子保存事务内判断方向，复用现有重叠关系、稳定身份、片段快照、循环检查和撤销机制。接入文本完整编辑、独立例句完整编辑、两类原位编辑（含旧固定词格入口）及新建句子的保存；轨道、调查和引用中的共用句子编辑器走同一保存入口。

仅在词格两行均有内容、每个片段非空、边界对应且组合有效时参与判断。每个由 `~` 相连的明确两端结构中，一端仅包含已登记语法标签，另一端包含词汇释义，就把语法端关联到词汇端；两端方向均支持。标签按所属语言及登记别名识别，复用已有英文同形标签规则；大小写或字母文字本身不能证明标签身份。混合标注如 `thick.PL` 保留词汇性质。未登记的疑似标签、两端同为语法或词汇标注，以及三段以上未明确组合的结构不自动建立关系。

已组合的不连续基底可以引用多个片段；不把中缀两侧擅自组合成一个词干。自动关系的重叠类型为“未细分”，不推断音变、复制范围或功能，不改写语素、IPA、标注、翻译、词典关联及词典定义。

既有关系全部保留，包括人工关系、待核对关系和之前自动创建的关系。相关词格不再新增竞争关系。原位编辑后仍可定位到的旧关系只影响其词格；无法确定旧关系对应哪个当前词格时保守跳过本句。词格自身有语码标记时留待手动处理，避免套用错误语言的标签表；其他明确词格可正常识别。

候选读取、关系预览、形态关系管理、导入和撤销／重做不执行推断，不新增自动识别按钮或入口。完整独立例句保存显式传递 `sentence_edit=True`，与语言导入共用的底层写入保持原交换语义。重复保存不重复建关系，提交失败则与句子修改一起回滚。原位草稿中主动解除的关系不会在同一次保存时被重建。

现有重叠提示改为说明保存行为，中英文同步；提示和关系对话框说明接入共用辅助文字角色，保持键盘保存与原有手动操作。

## 存储范围

本轮没有新增数据库字段、持久化 JSON 结构或第二套关系缓存。推断从 `grammar_tags` 读取当前语言标签，从编辑后的词格及既有分段取得对应关系，语码范围按稳定身份筛选。

保存沿用原重叠分析扩展：`sentence_text_rows.extra` 中的 `reduplications`，以及 `sentence_word_rows.extra` 中的 `redup_id` 和已有 `morph_groups`。这些是当前系统已有的形态分析扩展，仍承担旧项目、Typst 附注、语言交换及旧撤销兼容；本轮未迁移其存储格式，也未对关系进行双写。句子普通字段继续使用 SQLite 类型化列。
