# 整词分析复用

2026-10-26，纳入0.9.01026.4同版本重建。

## 使用

在任意已保存例句的“补全空白标注”窗口中，程序同时查找词典语素候选和已有材料中的整词分析。例如，本句为`homeka`，已有已关联材料为`home-ka / house-LOC`，可将后者作为整词候选。

窗口的“整词匹配忽略”涵盖系统词形分析器支持的全部边界：`-`、`=`、`+`、重叠标记`~`和中缀括号`<>`，默认全开；中缀括号成对开关，兼容源码中的`\~`。忽略括号只移除界定符，保留中缀内的音段，例如`s<um>ab`匹配`sumab`。选项由后端的实际解析规则提供，只影响整词历史匹配。声调、变音符号、长音、大小写、标点以及`#sub[...]`中的内容保留；Unicode规范等价的字符可以匹配。标注行的点号、斜线等有各自的组合／关系含义，不作为词形边界删除。不按近似读音推断，也不跨词格拼接。

整词候选显示原词形、完整标注、关联义项、来源句的IPA／翻译和已关联用例数。`home-ka`与`home=ka`分别保留；相同标注但不同义项也分别保留，并显示各自的义项位置和释义。排序优先完全相同的切分，再按已关联用例数排列；用例数是材料出现次数，不代表人工核准次数或模型置信度。

整词分析必须逐词手动选择；“选择唯一词典匹配”仍只选择原有词典候选。选择整词分析会清除同一词格的语素选择，反之亦然，其他词格保留。确认后一次采用切分、标注和词典关联，可一步撤销／重做；后续修改词典释义仍正常联动。

## 适用范围

- 仅向整个标注为空、尚无词典关联的词格提供整词复用。已有明确切分必须与候选一致，不能通过补全改写为另一种切分。已有非空标注、手工组合、重叠或中缀确认保持原样。
- 来源须在同一有效语言内、语素标注完整，且所有语素均有有效关联，或有唯一的有效整词关联。失效、部分关联和本句单独覆盖的标注不作为学习来源。
- 支持已确认中缀、词格内重叠关系、环缀等人工组合及有效形态组分关联，采用时一并保留分析与关联。组ID和重叠身份重新分配，保持目标原有词格ID，避免串到来源。
- 若重叠基底指向其他词格，或原基底已经失效，显示原因并要求在本句的形态分析中确认基底，不按同形词猜配。带语码标记的来源句／被语码标记覆盖的目标词格仍不自动迁移语码关系。
- 不复制来源的备注、附加层、合法性判断、角色、录音或其他句级信息；目标词格稳定身份、附加层和既有引用保留。
- 目前用于单句“补全空白标注”的共用窗口，文本、独立句及各模块引用沿用同一入口；全库自动关联尚未改为整词批量复用，也没有引入外部模型或上下文预测。

## 实现与验证

`word_analysis_memory.py`维护可重建的词形索引；句子保存、删除、撤销、恢复及文本语言变化只标记相关句子。首次预览建立索引，以后刷新发生变化的句子；候选的关联、义项、词形和来源状态每次重新核对。预览令牌包含当前分析及来源，过期选择不能写入。确认在现有事务与撤销机制内完成，任何关联保存失败都会整体回滚。

四个`word_analysis_*`表是派生数据，不加入业务撤销和JSON备份；版本标记使旧的三符号索引自动重建一次，以后继续增量刷新。完整SQLite备份可携带这些表，但移除本模块的派生触发器，由启动时的可信源码重新建立，恢复端仍拒绝外来触发器。JSON恢复和语言导入从业务材料重新建立索引，不迁移或重编号原词格／例句。源码接入在`sentence_dictionary.py`，界面沿用`web/sentence-dictionary.js`及其样式。


## 快捷入典与词典例句刷新

“收入词典”的词类输入框可从本语言已有顶层词类选择，也可键入新词类。已有类沿用现有名称，新类随词条／新用法的保存自动登记，和关联一起撤销；取消或保存失败不会留下新类。

从词典例句区入典后，只更新相关例句卡片、左侧目录／计数和关联面板，保留原例句页码及词条详情。若替换关联使该例句不再属于当前词条，则更新当前例句页，保留词条头部和其他内容。本副本核对范围见[验证记录](VERIFICATION.md)；相关回归测试随源码提供。
