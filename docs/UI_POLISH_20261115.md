## 外观修正

1. 分析频次表的纯文字单元格原先顶端对齐，而词形、次数链接按钮带有控件行框，首行基线相差约 7.9px。共用样式改为单元格基线对齐，文字按钮采用首行基线；普通词形、语素、自定义结果及多行词形均核验。研究字体与共用控件高度保留。
2. 轨道左上工具栏的列表、新建、录音、换源和确认改用共用 SVG 图标按钮，保留原处理程序、提示和读屏名称。图标盒在按钮两轴居中，不再依赖字符字面的字体留白。
3. 首页轮播句子的焦点外框及阴影移除；键盘焦点使用原文下划线，继续可用键盘打开原句。
4. 英文起止标签改为 `Start`／`End`，秒单位保留在输入框提示及读屏名称。删去中英文空闲状态的“仅调整时间／不改变正文”说明，保留待保存、成功及错误反馈。时间栏按共用控件高度随字号伸缩，窄窗中的大字号双列按钮不再被裁切，纵向可以滚动到余下控件。

## 句子块的 IPA

本轮实测，已有服务端读取路径在保存后使用关联原句的当前 IPA，保存、撤销和重做均能更新；输入尚未保存时则一直显示上次保存值。新增当前编辑草稿的即时预览，同一句的可见句子块、悬停文字和读屏文字随 IPA 输入更新；没有 IPA 时依次显示当前翻译与空句提示。移入视口的区间也从同一草稿读取。

预览不修改区间数据或正文，不更换已有区间节点，不影响输入焦点、播放和选择。取消编辑重新读取保存值；保存仍通过原编辑器及历史记录完成。按来源种类、稳定句子身份及所属语言匹配，事件、语言片段和失效关联不使用句子草稿。

正式项目按只读事务逐一比较 **7 条时间轴、111 个句子区间** 的实际详情结果与权威原句：**0 处差异**；全部关联可解析，全部区间标签为空，没有旧 IPA 副本需要清理。SQLite 快速完整性与外键检查通过。本轮没有改写正式项目、区间标签或撤销记录，也没有新增正文副本或存储迁移。该核对描述当前项目状态，不能据此断言用户先前看到的某一句显示已经复现。
