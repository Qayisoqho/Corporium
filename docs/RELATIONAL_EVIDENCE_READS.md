# 例证页读取与 JSON 存储盘点

2026-11-12，Corporium 0.9.01108 源码

本文记录例证读取阶段的测量与当时的存储盘点。后续四个正文列已移除，最新数据结构及开发约定见 [SQLite 正文与存储约定](SQLITE_STORAGE.md)。

## 约 500 毫秒的构成

复用已有密集测试库，含 10,000 条文本句、1,000 条独立例句、11,000 条独立词典关联和 3,014 个词条／语素。剖析独立例证后台接口的一次 20 条响应，耗时约 502 ms。约 452 ms 用于组装例证卡，其中语素着色约 308 ms。着色逐卡重复读取词典目标类型，查询还经过生成语素显示正文的视图。逐卡读取标注约 71 ms，按语言分析约 50 ms，Python JSON 解码合计约 16 ms。这些调用存在嵌套，耗时不能相加。

浏览器打开词条时还预取该词条的全部独立例证，随后再次请求当前页。测试词条的多余响应约 29 MB。页面现在并行读取文本语料例证和独立例证的当前页。语素页也从服务端按页读取独立例证。

## SQLite 读取

- `sentence_text_rows` 保存正文、IPA、译文、来源等列和字段存在标记。`sentence_word_rows` 按句子及词格位置存取词形、标注和附带字段。已准备的句子直接从这些行及现有标注关系组装。旧句首次按需要从原记录拆分，编辑和撤销仅清除涉及句子的派生行。
- 页内附加标注、释义继承、语素着色、语码和独立例句编号按批读取。已写入的关联和标注继续使用 `independent_links`、`annotation_cells`、`gloss_bindings` 等关系。
- `corpus_sentence_keys` 保存文本句身份、文本顺序位置和语言覆盖。已有搜索范围记录可用于初始化。缺少的键在访问关联词条时补齐，打开旧项目无需扫描全库正文来建这份目录。只读或并发写入时，可在同一查询快照内从相关原记录取得缺少的字段。进程内分页缓存保留有上限的排序身份及计数。
- `dictionary_value_rows` 为访问到的词条和语素保存带类型的 SQLite 值、父节点和顺序。词典详情、语素详情和词典派生标注可以直接组装用法、义项、变体、书写及构词分析。数组顺序、空值、真假值和大整数随值保留。词典保存和撤销会清除相应条目的派生行。

## 前后对照

后台数值以毫秒计。使用同一份隔离库运行两份源码，各测 9 次。包含连接、查询、组装、响应编码和关闭。两类接口都返回 20 张卡，整页响应的语义指纹前后一致。文本语料例证的首次打开须准备该词条的排序和计数。

| 后台操作 | 改动前 P50 | 改动后 P50 | 重复读取 SELECT 次数 |
| --- | ---: | ---: | ---: |
| 独立例证，形式筛选命中 1,000 条 | 441 | 86 | 224 → 16 |
| 文本语料例证，命中 10,000 条 | 1,941 | 122 | 328 → 16 |

文本语料例证在新进程中的第一次请求约 1,883 → 625 ms。语料排序键已落盘，进程仍要首次整理该词条的 10,000 条关联。在既有上限库中，读取 50,000 条文本句正文建立排序键的对照耗时约 9.85 秒。复用已准备的搜索目录可复制 49,999 条键，耗时约 258 ms，剩下的一条按需补齐。这两项是目录操作计时。

本机浏览器从打开同一词条到两组例证显示完成，旧版中文两次约 24.4–25.5 秒。新版中文首次约 2.72 秒，后两次约 1.29 秒，英文三次约 0.98–1.29 秒。首屏两组各 20 张卡，独立例证只发一份约 0.58 MB 的分页响应。界面总耗时还包含其他词典资料请求和卡片排版。中英文 600 × 900、150% 字号实测均可翻页，例证分页栏与详情没有横向溢出。

## 仍以 JSON 保存的资料

| 范围 | 目前保存方式 |
| --- | --- |
| 文本句和独立例句 | `entries.body`、`dictionary_examples.body` 仍是写入来源。`history.body` 保存历史句子。句子派生行的 `extra` 仍保存未单列的词格和句子属性。原 Typst 文件内容可作为普通文本保存。 |
| 词条和语素定义 | `lexemes.body`、`morphemes.body` 仍是写入来源，含义项、变体、书写形式、构词与组分、变形表、用法标签、转换及归并历史。关联可选身份与继承释义已分别使用 `independent_dictionary_keys`、`gloss_meanings`。 |
| 例证附带资料 | `independent_links.payload`、`independent_words.source`、`independent_word_overrides.source/word`、`unit_segments.body`、`component_links.body`、`morpheme_components.body`、`morphology_analyses.features`、`gloss_bindings.pattern`、`code_spans.word_ids/snapshot`。关联身份、词格顺序和多数标注值已有列或关系行。 |
| 项目目录和研究附记 | `languages.metadata`、`text_info.metadata`、`texts.errors`、`grammar_tags.aliases`、`morph_class_templates.body`、`collaborator_assignments.people`、时间轴语言标记／说话者／媒体的 `metadata`、`object_media.body`，以及调查节点和证据、笔记、例句组、同义关系的扩展内容。 |
| 撤销、分析记录和索引 | `undo_steps.changes` 包含压缩或历史 JSON。分析查询、摘要、固定结果及研究证据仍有 JSON 内容。搜索资料和词格分析的一部分派生缓存也使用 JSON，例如 `material_search_documents.source/fields/classes`、`material_search_options.body`、`gloss_search_recipes.body/output`。 |

本轮改造了读取路径，四个正文列仍保留原始权威记录。最终移除正文 JSON 要迁移保存、批量修改、全库校验、同步、搜索索引和撤销恢复，并验证既有归并记录与扩展字段。当前验证覆盖按页读取、原存储兼容和交换格式。

## 导入导出和旧项目

读取同一个旧库的所有 10,000 条文本句、1,000 条独立例句、2,014 条词条和 1,000 个语素，按字段核对拆分后的数据。旧项目内的正文原记录继续可用。备份包从快照移除派生表，恢复后可重新准备。

密集库的语言 JSON 导出前后均为 257,041,086 字节，SHA-256 相同。语言包导入及身份重映射、原有 JSON 备份和 SQLite 备份恢复、Typst、Word、Excel 交换通过相关回归。导入导出仍接受原有文件格式。测试使用既有材料的隔离副本。安装包沿用上一构建。

两份源码各通过 742 项前端测试和 816 条样式审计。隔离项目实测中英文 600 × 900、150% 字号，检查研究字体、当前页请求、首两页内容及键盘翻页。公开源码副本也实测了收起窄窗侧栏后的鼠标翻页。
