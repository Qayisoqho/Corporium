# 语素语码：数据、显示与兼容

2026-11-08源码开发版，0.9.01101。新功能尚未进入现有安装包。[核验报告](../build/code-morphemes-20261108/REPORT.html)。

## 单位与操作

标记的是本句中的语素出现，不是词典中的语素类型。语素由既有切分分析产生；点号语法标签、连接符、标点、音系边界不是单独单位。环缀及显式语素组合整体选择，中缀宿主的多个片段仍属于同一语素。形式与gloss无法可靠配对或中缀未确认时，保留阅读和旧标记，但先整理切分才能新选该词的语素。

“更多 → 语码标记”中点击小格单选，Shift连选，Ctrl／⌘切换，点击词形选整词。新范围须连续；保存过的范围在词格移动／插入后可以成为分散范围，继续保留原身份。语言和备注与范围一起保存，可撤销。一个语素不接受重叠标记，同一词格内不同语素可以分别指定语言。

## 存储与身份

沿用code_spans、code_time_links和code_sentence_index，无新增列。word_ids继续保存父词格ID，使现有保护、复制和语言交换入口不失效。旧snapshot为“父ID → 原词形字符串”；新snapshot为“父ID → v2对象”：

```json
{"version":2,"form":"root-na","units":[{"key":"1:host","kind":"simple","form":"na","members":[],"fragments":[{"start":5,"end":7,"text":"na"}]}]}
```

key是稳定父词格内的逻辑切分地址，结合原词形和语素kind／成员／形式片段检查，不作为脱离快照的永久语素ID。API使用morpheme_ids传选择，旧客户端word_ids入口继续兼容。一个范围的快照必须全部为旧格式或全部为v2，混合格式交换包明确拒绝并回滚。

词形完全相同、逻辑语素的形式结构仍对应时，可使用当前gloss片段显示；这允许修正gloss文字。父词形不同、组分重新组合或无法配对时保留原依据，不用新位置、同形或词典类型推断继承。此实现采取保守策略：即使只改同词中另一成分的拼写，也需重新选定原标记范围。保存的旧依据和重新选择／移除入口持续存在，不添加没有处理入口的通用“待核对”徽标。

旧词格标记的语言／备注修改沿用原word_ids，包含当前无法展开的词格。只有明确重新选择语素才转换到v2，不能以自动解析出的子集替代完整旧范围。目录刷新时若正文、范围或手动时间对应变化，阻止接受新令牌沿用旧草稿，要求关闭重开。

## 共享显示和计数

code_morphemes.layout生成只读单元和两行原字符串的分区；原文、IPA、词形、gloss、词典和语料切分不因展示而改写。code_switching.profile按实际形式片段顺序计算连续范围，默认语言填充未标语素；空格／标点／边界不计语码。不同语码可出现在同一个词中，整句同一外语不算混用，未确定语码不臆断成一种语言。

前端CorporiumCodes.pair在共用renderWord入口生成对应列，保留已有morpheme颜色、语法标签小型大写、上下标及附加层。标记只落在语素片段，分隔符保持原样。连续同语码、同备注范围只在末片段的gloss后显示简称；不连续环缀等可显示多个简称。简称使用普通界面字形，不挤占声调或叠在其他文字上，提供悬停、点击及键盘详情。

文本、独立例句／组、词典和语素例证、调查、轨道、分析上下文均复用该入口。筛选与统计继续按原句去重，不把多片段或多处引用算成多个句子。原文／IPA局部语言着色没有可靠字符对齐，目前不实现。

## 复制、时间与撤销

现有copy_spans／import_bundle只需重映射外层父词格ID，词内key和结构随该词复制。单句、词格转移和语言交换保留独立新身份与原快照，不复制录音时间对应；整篇文本复制继续独立复制相关时间轴及对应。无效原身份仍保持为原依据，不能按词序重新挂接。

手动对应须同句、同工作区、同语码。仅改语言会同步已关联片段；范围或原形依据改变后重新选定会解除旧对应并保留片段。未改变覆盖的旧整词转换为全部语素时可以保留对应。没有自动推算语素起止时间。

带格式复制读取显示片段，保留标记细线和普通字形简称，并保持语法标签／上下标规则。本轮验证了HTML和纯文本载荷，未操作系统剪贴板，未重新验收真实Word粘贴。普通DOCX文本交换不重建研究关系，完整还原用语言包或项目备份。撤销仍使用原journal表和事务，code_sentence_index为派生句级索引。
