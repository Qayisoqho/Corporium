# 现场录音

更新于2026-10-26，当前版本 **0.9.01026.3**。Windows采集端，中英文使用同一套流程。

## 入口

- 词典／语素：当前条目媒体操作行中的“录音”，可指定整个条目或具体变体／主要部分。
- 独立例句：尚无音频关联时，“录音”位于“管理媒体”左侧。已有附件或时间轴音频时，句旁不再显示录音按钮。
- 媒体管理：左侧列表下方，“录音”与“＋添加媒体”同行，始终可继续录制；新关联自动更新列表。
- 时间轴：侧栏“●录音”，保存为新时间轴，不替换已有媒体。

文本语料没有逐句录音入口，后端也拒绝创建文本句单独录音。已有长篇媒体、句级时间轴对齐、播放与过去形成的关联继续保留。

## 试音与正式录音

“试音10秒”只在内存保留声音，不写入项目或生成试音文件。结束后仍“开始录音”，可试听或“下载”，不能直接关联为正式录音。关闭面板清除已结束试音；面板关闭时试音仍在进行的，结束后清除。下一次录制也替换该项目上一次试音。只有用户明确下载时，才写出所选WAV文件。

正式录音持续自动保存在项目最外层的 media/recordings/语言名及固定代号/日期/录制身份/。停止后可试听、下载、“保存并关联”或“另录一次”；后者另存文件，不覆盖原件。未关联正式录音可在同一对象的面板继续处理。旧data/media及升级前已有文件不会被自动迁移或删除。

独立例句以源句身份关联，在组、词典引用、调查等共享视图中一致显示；不改变abc、Q/A、合法性或固定号。已有附件或时间轴音频时隐藏句旁录音，移除后恢复，撤销／重做同步更新。发言人设置与已有手动句子人员分开。

## 规格与提示

优先选择设备支持的48kHz／24bit／单声道，也可选44.1／48／96kHz、16／24bit及单双声道。保存无压缩PCM WAV；不支持的手选组合会报错，不静默转换。24bit保存不等于证明麦克风有效精度达到24bit。

电平以dBFS显示，提示过载、低电平、输入中断及缓冲风险。提示留在面板内，不反复弹窗或重写，不阻挡关闭和停止。程序不添加降噪／自动增益／回声消除，设备和系统的音效需自行关闭。

录音中不能关闭程序、切换项目或界面语言；关闭面板后仍可在工作区顶部停止。词条／语素／独立句单次一小时，时间轴三小时，并受WAV大小上限约束；达到上限或磁盘不足时停止并保留已录部分，可另起一段。

## 恢复与备份

正式录音持续写盘，每秒刷新WAV长度与恢复记录。异常退出后可恢复已写部分，无法保证找回断电时尚未落盘的声音。撤销或放弃关联不立即删原件。

已关联原件随完整备份携带；语言包自动携带词条／语素／独立句附件，时间轴媒体可选携带。未关联正式录音尚未进入业务备份，迁移前需关联或另行保留media目录。试音不参与备份／交换。

## 验证与边界

测试入口和本公开副本实际执行范围见[验证记录](VERIFICATION.md)。合成声音／模拟设备测试不等于真实麦克风和现场音质验收；首次使用先试音。
