# 分析释义与词典交互修复（2026-11-15，仅源码）

发布补记（2026-11-16）：本文功能已纳入 **0.9.01115 同号重建安装包**。[本次构建与核验](REBUILD_0.9.01115_20261116.md)。下方“仅源码／未打包”和测试数字保留开发当轮事实。

本轮接续 0.9.01115 的源码，不改版本号、不重新打包；既有安装包尚不包含本轮修复。工作副本与 `github/` 公开副本同步。所有写入验证使用隔离虚构项目。

## 修复范围

1. 分析频次表的意义列使用已有的有效释义规则组合自由释义与语法标签，尊重标签显示开关。普通语素统计与自定义词条／语素筛选均接入；义项只有标签时也可作为首个非空释义。沿用 `3` 与 `SG` 合成 `3SG`、标签去重和研究内容渲染，不修改词典正文。
2. 词条侧栏输入时逐字上滚源于吸顶检索区在滚动父容器设置 `scroll-padding-top`，浏览器不断将输入光标滚入该内边距。改为仅在词条和语素列表条目设置 `scroll-margin-block-start`，保留列表定位避让。中英文窄窗中“已设条件”首次出现可能使摘要换行，这是检索区高度变化；后续连续输入保持滚动位置。
3. 原清空按钮随旧检索容器删除而消失。将其移入始终可见的查询控件行，与高级条件内部按钮使用不同身份；两处均清空关键词、条件、类别及页码。窄窗允许控件换行，保留 Enter 激活。
4. 汉语分格／快捷词条编辑失焦时重复 `append` 候选列表，导致按下的候选离开原节点位置，点击不能完成。仅在实际换容器时移动候选，完整／快捷编辑、普通／汉语模式及 Enter／按钮检索均核验首次单击、保存和撤销。
5. 调查笔记标题和预览同时受到文字裁边与省略遮罩影响。将其接入既有共用字形保护规则，按行高与大写字高计算对称留白，恢复汉字、附加符号和下伸部；保留全局字体字号、省略和笔记编辑保存。
