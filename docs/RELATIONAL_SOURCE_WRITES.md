# 句子和词典内容的关系写入

2026-11-12，Corporium 0.9.01108 源码

本文保留关系写入与双写阶段的实测。后续已切换查询及索引、停止双写并移除四个正文列。[当前方案与计时](SQLITE_STORAGE.md)。

## 保存、校验与撤销

- 文本句和独立例句的保存使用 `sentence_text_rows` 和 `sentence_word_rows`。正文、IPA、译文、来源和词格有独立列。已有词格按位置比较和更新，独立例句关联与解绑时保留的标注继续在各自的关系行维护。
- 词条和语素的保存将用法、义项、变体和构词写到 `dictionary_value_rows`。值的类型、父节点、位置与内容分别保存。词典引用所用的义项、变体和变形表身份由同一事务直接更新。已准备的当前词条、同形组和结构校验从这些关系读取。
- 新撤销记录可保留结构化的正文前后值，撤销和重做通过关系写入入口恢复。旧记录中的正文字符串在恢复时转换一次。释义继承使用独立副本分析旧记录，保存的旧正文不会被补入展示字段。
- Typst、Word、Excel、语言数据包和旧项目 JSON 恢复进入相同的写入入口。SQLite 备份保存已经准备的句子与词典关系行，复用既有的索引重建机制。备份对外仍使用原有正文和撤销格式。

## 旧库核对及列删除状态

在既有密集库的隔离副本中逐条准备并核对 10,000 条文本句、1,000 条独立例句、2,014 条词条和 1,000 个语素。共得到 11,000 条正文行、132,000 条词格行和 501,467 条词典值行。全库准备加核对约 15.3 秒，这是一项专项检查。日常打开旧项目按需准备访问的记录。SQLite 快速完整性检查通过，无外键错误。

语言 JSON 前后各 257,041,086 字节，SHA-256 一致。语言数据包身份重映射、旧版项目 JSON、SQLite 项目包、Typst、Word 和 Excel 的导入导出通过回归。旧撤销还原、带继承释义的词格、删除被引用的义项时回滚均有专项检查。

四个旧正文列仍作为兼容投影在同一事务维护。实际在隔离副本中试删，各列都有仍在使用的依赖。文本句排序键触发器、旧独立关联导入触发器、词条同形排序表达式索引和语素公共词典视图分别是 SQLite 首次报告的依赖。搜索、全文索引、排序和部分交换读取仍访问这些列。完全移除正文 JSON 列这一阶段尚未完成。词格附带的分析与扩展值也仍有按格保存的 JSON。

## 前后耗时

复用既有千句项目，含 1,000 条文本句、100 条独立例句、100 条词条和 104 个语素。两版用相同的草稿准备流程，各操作提交并撤销 5 次。表中为后台中位数，包含应用请求、提交和响应编码。编辑器预检与页面刷新单独进行。两版各 30 次撤销后均逐条比对正文一致。

| 操作 | 保存前 → 后 | 撤销前 → 后 |
| --- | ---: | ---: |
| 文本句已关联词格 | 132 → 143 ms | 139 → 146 ms |
| 独立例句词格 | 123 → 127 ms | 140 → 141 ms |
| 词条义项定义 | 99 → 116 ms | 129 → 133 ms |
| 词条变体备注 | 147 → 116 ms | 196 → 138 ms |
| 词条变体词形 | 106 → 117 ms | 138 → 137 ms |
| 构词组分更换语素 | 105 → 122 ms | 139 → 141 ms |

变体备注的校验证明确认变体身份和词形等引用字段未动，省去了重复的完整检查。本轮保留兼容列写入，普通保存的额外耗时如表所示。

两份源码各通过 816 条样式审计。隔离项目中英文均以 600 × 900、150% 字号打开独立例句编辑器，内容宽度与容器宽度均为 547 px。计时、旧库逐条对照和界面记录保存在本机 `build/relational-write-20261112/`。两份源码已同步，安装包沿用上一构建。
