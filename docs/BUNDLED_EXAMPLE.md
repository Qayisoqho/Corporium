# 随附 Tëlira 示例

2026-11-16。Tëlira 是 Corporium 使用的虚构示例语言。当前随附英文材料包含 573 个词条、2 篇文本、168 条句子和 1,221 个释义继承关联；两篇文本为 *Come with Us Today* 和 *The Name the River Kept*。不包含媒体或正式研究资料。

## 两种使用方式

| 用途 | 文件与操作 |
| --- | --- |
| 单独打开完整示例项目 | 启动页选择“打开 Tëlira 示例”，选一个空目录；程序恢复随附的 `packaging/examples/Telira.corporium-backup`。也可从“恢复完整备份”选择该文件。 |
| 将示例语言加入已有项目 | 在语言管理中导入 `packaging/examples/Telira.corporium`；这是语言交换包，作为新语言导入。 |

两条路径都不会替换已有语言或研究项目。SQLite 项目快照需要 Corporium 0.9.01115 或兼容源码；11 月 16 日同版本重建安装包已经包含快照及优先恢复逻辑。之前的 11 月 15 日首包只有旧语言包，不能仅凭版本号判断是否包含这次资源更新。

## 开发与分发

项目快照是标准 SQLite 备份 v2，仅含 `manifest.json` 和 `project.sqlite3`，没有工作库撤销历史、媒体或外部文件引用。语言包仍是原有的 JSON 交换格式；这不改变项目权威正文使用类型化 SQLite 列与关系行的约定。

开发主目录从虚构工作库的只读副本生成两份资源。公开源码只验证随附文件，不访问本机制作项目。工作库、私有验证材料和历史备份不随公开源码或安装包分发。启动恢复失败不切换项目；仅在 SQLite 示例资源缺失时兼容旧语言包。

参见[SQLite 存储约定](SQLITE_STORAGE.md)、[同版本重建记录](REBUILD_0.9.01115_20261116.md)和[发布核验](RELEASE_0.9.01115.md)。
