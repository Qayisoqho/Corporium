## Design Context

### Users
Corporium is a local research workspace for field linguists working with multilingual corpora, interlinear glosses, a lexicon, elicitation and media alignment.

### Brand Personality
Scholarly, calm and precise. Preserve the established refine2 interface and the user's selected theme.

### Aesthetic Direction
Keep the existing compact blue and gray workspace, numbered senses and restrained reading layout. Use the user's ordered global font stack for interface text. The Corporium brand wordmark stays in Junicode, including the home title, enter-button wordmark and footer brand. Keep grammatical labels distinct from usage tags in English.

### Design Principles

- Follow [docs/UI_STANDARDS.md](docs/UI_STANDARDS.md) and `web/ui-standards.css`: interface text and controls 15px, secondary/help text 14px, small section headings 18px at 100%; standard/compact controls 36px/32px, scaled by the user's settings. Density changes height, not text size. Use shared semantic roles rather than panel-specific sizes.
- Apply interface size roles across all relevant workspaces, editors and dialogs, including homophones, phonology, timelines, notes, settings and startup. Screenshots identify examples rather than the full audit scope. Preserve research typography and established interaction behavior.
- Run the read-only `tools/ui_style_audit.py --check` on both source copies, review its explicit exceptions, and verify computed styles in representative open, editing, result and pagination states. A source scan alone is not visual verification.
- Align related text by baseline and align icons independently; allow long content to wrap.
- Respect global font order and text size. Preserve independent annotation settings outside explicitly requested changes.
- The rotating home example uses its own language's IPA and translation row settings; an original without IPA uses that language's annotation font. Only rows explicitly set to follow global fonts inherit the global chain. Home interface captions use the global font, while the Corporium wordmark stays in Junicode.
- Verify Chinese and English, larger text and narrow windows using fictional projects.
- Preserve research content, object identity, existing handlers and keyboard behavior.
